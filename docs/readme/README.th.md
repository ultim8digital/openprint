ค้นหาสตูดิโอผลิตบนแผนที่ ตรวจสอบความสามารถของพวกเขา และติดต่อพวกเขาโดยตรง หากข้อมูลของเวิร์กช็อปของคุณยังไม่มี ให้เพิ่มข้อมูลติดต่อและบริการ: ข้อมูลจะแสดงทันที บันทึกลิงก์สำหรับจัดการส่วนตัวเพื่อแก้ไขหรือลบข้อมูลของคุณในภายหลัง แคตตาล็อกเริ่มต้นไม่มีบัญชีผู้ใช้ การยืนยันทางอีเมล หรือระบบการอนุมัติ

เรียกใช้ OpenPrint ด้วย Node.js 24 และ SQLite ในเครื่อง Vercel, Supabase ซึ่งเป็นผู้ให้บริการอีเมล, AI ที่ต้องเสียค่าใช้จ่าย และการเข้าสู่ระบบของบุคคลที่สาม ไม่จำเป็นต้องใช้ GitHub เป็นที่เก็บซอร์สโค้ดและเผยแพร่โค้ด เว็บไซต์ที่เปิดให้ส่งผลงานต้องมีเซิร์ฟเวอร์ API ที่ทำงานอยู่ [GitHub หน้า](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) เพียงอย่างเดียวไม่สามารถเรียกใช้ Node.js API หรือบันทึกการเปลี่ยนแปลงของผู้เยี่ยมชมได้

## คุณสมบัติของแค็ตตาล็อก

- ค้นหาตามชื่อ เมือง และเทคโนโลยี แผนที่จะแสดงตำแหน่งที่ตรงกันโดยไม่ขึ้นอยู่กับการแบ่งหน้าของรายการ
- เผยแพร่โดยไม่ต้องมีบัญชี เลือกจุดบนแผนที่หรือป้อนพิกัด รายการที่ไม่มีพิกัดจะยังคงสามารถค้นหาได้
- แก้ไขหรือลบรายการ 1 รายการ พร้อมลิงก์ส่วนตัว การตรวจสอบเวอร์ชันจะช่วยป้องกันการแก้ไขที่ขัดแย้งกันในแท็บต่างๆ
- ค้นหาสตูดิโอที่มีอยู่แล้วก่อนทำการเผยแพร่ ชื่อ เมือง และที่อยู่ที่เป็นข้อมูลซ้ำจะถูกปฏิเสธโดยอัตโนมัติ
- นำเข้าแคตตาล็อกพร้อมระบุแหล่งที่มา ผู้ปฏิบัติงานไม่สามารถนำเข้าข้อมูลเพื่อแทนที่รายการที่เผยแพร่ด้วยตนเองได้
- ดูภาพไทล์ OpenStreetMap ภาพโดยไม่ต้องใช้คีย์ API ภาพไทล์จะโหลดเมื่อแสดงแผนที่ รวมถึงหน้าเริ่มต้นโดยค่าเริ่มต้น
- เลือกภาษาของส่วนติดต่อผู้ใช้จากเมนูภาษา อ่านไฟล์ README ฉบับเต็มในภาษาของคุณได้จากดัชนีภาษาด้านบน

การเผยแพร่ข้อมูลไม่ได้เป็นการยืนยันความเป็นเจ้าของธุรกิจหรือคุณภาพของบริการ โปรดยืนยันข้อมูลเกี่ยวกับอุปกรณ์ ความสามารถ และเงื่อนไขต่างๆ กับสตูดิโอ ผู้ที่มีลิงก์สำหรับการจัดการส่วนตัวสามารถควบคุมข้อมูลที่แสดงได้ โปรดเก็บข้อมูลนี้ไว้เป็นความลับ เนื่องจากไม่มีระบบกู้คืนอีเมล โปรดอ่าน [คู่มือการเผยแพร่ด้วยตนเอง](../../docs/OPEN_CATALOG.md)

## เรียกใช้โปรแกรมในเครื่องของคุณ

ติดตั้ง Node.js 24 คัดลอกแหล่งเก็บข้อมูลนี้ และรันคำสั่ง:

```sh
npm ci
npm run build
cp .env.example .env
npm start
```

Open `http://localhost:3000` การตั้งค่าเริ่มต้น `APP_MODE=catalog` ไม่จำเป็นต้องมีการตั้งค่าโดยผู้ดูแลระบบหรือผู้ใช้ กำหนดค่า `APP_URL`, HTTPS และการสำรองข้อมูลโดยใช้ [คู่มือการติดตั้งด้วยตนเอง](../../docs/SELF_HOSTING.md) นอกจากนี้ยังมี Docker Compose ให้ใช้งาน: `docker compose up --build -d`

การติดตั้งที่รองรับคือกระบวนการแอปพลิเคชันเดียว โดยมี SQLite อยู่ในดิสก์ภายใน ระบบจะเผยแพร่และจำกัดจำนวนคำขอโดยอัตโนมัติ เพื่อป้องกันการใช้งานในทางที่ผิด โดยไม่ต้องมีระบบตรวจสอบ IP ของสำนักงานที่ใช้ร่วมกันสามารถใช้โควต้าการเผยแพร่ร่วมกันได้ โปรดดู [ขีดจำกัดและพฤติกรรมการจัดการ](../../docs/OPEN_CATALOG.md) ก่อนเปิดใช้งานอินสแตนซ์สาธารณะ

ใช้เครื่องมือบรรทัดคำสั่ง [catalog import CLI](../../docs/CATALOG_IMPORT.md) สำหรับชุดข้อมูลที่มีอยู่ หลังจากตรวจสอบสิทธิ์ของชุดข้อมูลนั้นแล้ว ชุดข้อมูลอินสแตนซ์ การอัปโหลด และการสำรองข้อมูลจะไม่รวมอยู่ในคลังข้อมูลหรืออิมเมจคอนเทนเนอร์

## โหมดชุมชนและโหมด Neofab (ไม่บังคับ)

ตั้งค่า `APP_MODE=community` อย่างชัดเจนเพื่อเปิดใช้งานโครงการส่วนตัว การเสนอราคาจากผู้ให้บริการ คลังแบบจำลอง และ Neofab Studio กระบวนการเหล่านี้ใช้บัญชีและสิทธิ์ของตนเอง การสลับโหมดจะเก็บรักษาข้อมูลที่บันทึกไว้ โหมดแคตตาล็อกจะไม่เปิดเผยประวัติส่วนตัวของชุมชนผ่าน API หรือดำเนินการต่องานที่รออยู่ CAD

[Neofab สตูดิโอ](../../docs/NEOFAB_SETUP.md) รองรับเอกสารข้อมูลการผลิตแบบมีเวอร์ชัน รายการวัสดุ และการกำหนดค่าแบบตายตัว CAD พร้อมการส่งออกในรูปแบบ STEP/STL CAD และ AI เป็นตัวเลือกเสริม ข้อเสนอ AI ต้องผ่านการตรวจสอบและขั้นตอนการสมัครแยกต่างหาก ข้อเสนอเหล่านี้จะไม่เผยแพร่คำสั่งซื้อหรือสร้างรูปทรงโดยอัตโนมัติ CAM, G-code และการตรวจสอบความถูกต้องของการผลิตจริงยังไม่ได้นำมาใช้งาน

## สิทธิในข้อมูลและความเป็นส่วนตัว

ใบอนุญาตซอฟต์แวร์ MIT ไม่ได้ให้สิทธิ์ในการใช้ข้อมูลทางธุรกิจที่นำเข้า การอ้างอิงแหล่งที่มาเพียงอย่างเดียวไม่ถือเป็นการอนุญาตให้คัดลอกข้อมูลจาก Google Maps, 2GIS, Yandex Maps หรือแหล่งข้อมูลอื่น ๆ ตรวจสอบสิทธิ์ในการจัดเก็บ เผยแพร่ และแจกจ่ายข้อมูลก่อนใช้งานชุดข้อมูล โปรดดู [ขอบเขตการตรวจสอบและที่มาของข้อมูล](../../docs/DATA_PROVENANCE.md)

ข้อมูลติดต่อที่เผยแพร่ด้วยตนเองเป็นข้อมูลสาธารณะ ส่วนข้อมูลสำคัญสำหรับการจัดการเป็นข้อมูลส่วนตัว เก็บฐานข้อมูลและไฟล์สำรองไว้ในตำแหน่งที่ไม่ได้เปิดให้เข้าถึงโดยทั่วไป และระบุข้อมูลติดต่อสำหรับแจ้งแก้ไขหรือขอให้ลบข้อมูล โปรดอ่าน [นโยบายความเป็นส่วนตัว](../../PRIVACY.md) และ [มาตรการรักษาความปลอดภัย](../../SECURITY.md) ก่อนใช้งาน

GitHub ตรวจสอบประเภทของการดำเนินการ API และขั้นตอนการทำงานของเบราว์เซอร์ รวมถึงคอนเทนเนอร์เริ่มต้นและคอนเทนเนอร์แบบดั้งเดิม CAD การทดสอบใช้ข้อมูลที่สร้างขึ้น การบันทึกหลักฐานที่ถูกต้อง ขอบเขตการทดสอบ และขีดจำกัดที่เหลือ จะอยู่ในส่วน [การตรวจสอบความถูกต้อง](../../docs/VALIDATION.md) และ [ขอบเขตผลิตภัณฑ์](../../docs/PRODUCT.md)

ไฟล์ README ภาษาอังกฤษเป็นเอกสารอ้างอิงสำหรับฉบับแปลฉบับสมบูรณ์ [ดัชนีภาษา](../../docs/i18n/README.md) มีข้อมูลเกี่ยวกับการบำรุงรักษาและการตรวจสอบการแปล การปรับให้เข้ากับภาษาท้องถิ่นจะไม่แปลรายการที่ผู้ใช้สร้างขึ้น เนื้อหาของโครงการ หรือข้อมูลทางเทคนิคภายนอกทั้งหมด

## การอนุญาตใช้งานและการมีส่วนร่วม

แหล่งข้อมูลต้นฉบับ ส่วนติดต่อผู้ใช้ ภาพประกอบ SVG เอกสารประกอบ และเครื่องมือสร้างแบบจำลองแบบพารามิเตอร์ ได้รับอนุญาตภายใต้ [MIT](../../LICENSE) ส่วนประกอบอื่นๆ ยังคงมีข้อกำหนดและเงื่อนไขของตนเอง โมเดลของผู้ใช้มีข้อกำหนดและเงื่อนไขแยกต่างหาก ซึ่งผู้สร้างเป็นผู้กำหนด โปรไฟล์ตัวอย่างและข้อความสั้นๆ รวมถึงแบบจำลองตัวอย่างที่สร้างขึ้นสามแบบ จะอยู่ภายใต้ CC0 ส่วนเครื่องมือสร้างแบบจำลองยังคงเป็น MIT ดู [ข้อกำหนดและเงื่อนไขของบุคคลที่สาม](../../THIRD_PARTY_NOTICES.md)

การพัฒนาอิสระนี้ต่อยอดแนวคิดจาก [3d-online.app](https://3d-online.app) บัญชีผู้ใช้เดิม, ข้อมูลลับ, ประวัติ Git ส่วนตัว และไฟล์ของผู้ใช้จะไม่รวมอยู่ด้วย คอมไพเลอร์ MIT Neofab CAD ที่ปรับปรุงแล้วยังคงรักษา [ใบอนุญาตและข้อความแสดงแหล่งที่มาเดิม](../../cad-worker/NOTICE.md) ไว้

การมีส่วนร่วมสามารถรวมถึงโค้ด การแก้ไขงานแปล การปรับปรุงประสบการณ์การใช้งาน ส่วนประกอบแบบพารามิเตอร์แบบเปิด การตรวจสอบการติดตั้ง และข้อเสนอแนะจากโรงงานจริง เริ่มต้นได้ที่ [CONTRIBUTING.md](../../CONTRIBUTING.md)
