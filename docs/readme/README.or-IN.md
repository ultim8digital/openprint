# OpenPrint

**ମୁଦ୍ରଣ ଶିଳ୍ପଶାଳା ଏବଂ କାରିଗରୀ ଶାଳାଗୁଡ଼ିକର ଏକ ଖୋଲା ସୂଚୀ। ଏଠାରେ କୌଣସି ପଞ୍ଜୀକରଣ କିମ୍ବା ମଡରେଟର ନାହିଁ।**

[Languages / Языки](../../docs/i18n/README.md) · [English](../../README.md) · [Русский](../../docs/readme/README.ru.md)

ମାନଚିତ୍ରରେ ଜଣେ ନିର୍ମାତାଙ୍କୁ ଖୋଜି, ସେମାନଙ୍କର କ୍ଷମତା ଯାଞ୍ଚ କରନ୍ତୁ ଏବଂ ସେମାନଙ୍କ ସହିତ ସିଧାସଳଖ ଯୋଗାଯୋଗ କରନ୍ତୁ। ଯଦି ଆପଣଙ୍କ କାରିଗରଶାଳା ତାଲିକାରେ ନାହିଁ, ତେବେ ସେଥିର ସମ୍ପର୍କ ଓ ସେବାଗୁଡ଼ିକ ଯୋଡି ଦିଅନ୍ତୁ: ତାଲିକା ତୁରନ୍ତ ଦେଖାଯିବ। ପରେ ସମ୍ପାଦନା କରିବା କିମ୍ବା ତାର ତାଲିକାକୁ ଡିଲିଟ୍ କରିବା ପାଇଁ ବ୍ୟକ୍ତିଗତ ପରିଚାଳନା ଲିଙ୍କକୁ ସଞ୍ଚୟ କରନ୍ତୁ। ଡିଫଲ୍ଟ କ୍ୟାଟାଲଗରେ କୌଣସି ଆକାଉଣ୍ଟ, ଇମେଲ୍ ଯାଞ୍ଚ କିମ୍ବା ଅନୁମୋଦନ ପଂକ୍ତି ନାହିଁ।

OpenPrint କୁ Node.js 24 ଏବଂ ସ୍ଥାନୀୟ SQLite ସହିତ ଚଲାନ୍ତୁ। Vercel, Supabase, ଏକ ଇମେଲ ପ୍ରଦାନକାରୀ, ଦାମ ଦେଇଥିବା ଏ.ଆଇ. ଏବଂ ତୃତୀୟ ପକ୍ଷ ଲଗିନ୍ ଆବଶ୍ୟକ ନୁହେଁ। GitHub ସୋର୍ସ ଏବଂ ରିଲିଜଗୁଡ଼ିକୁ ସଞ୍ଚୟ କରେ; ସମର୍ପିତ ପ୍ରବେଶକୁ ଗ୍ରହଣ କରୁଥିବା ଏକ ସାମୂହିକ ୱେବସାଇଟ୍‌କୁ ଏକ ଚାଲୁ API ସର୍ଭର ଆବଶ୍ୟକ। [GitHub ପେଜେସ୍](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) ନିଜେ Node.js API ଚଲାପାରିବ ନାହିଁ କିମ୍ବା ଅତିଥିଙ୍କ ପରିବର୍ତ୍ତନକୁ ସଞ୍ଚୟ କରିପାରିବ ନାହିଁ।

## କ୍ୟାଟାଲଗର ବିଶେଷତାଗୁଡ଼ିକ

- ନାମ, ସହର ଏବଂ ପ୍ରଯୁକ୍ତି ଦ୍ୱାରା ଅନ୍ୱେଷଣ କରନ୍ତୁ। ମ୍ୟାପରେ ତାଲିକାର ପେଜିନେସନ୍ ଉପରେ ନିର୍ଭର ନ କରି ସମ୍ବନ୍ଧିତ ସ୍ଥାନଗୁଡ଼ିକ ଦର୍ଶାୟିତ ହୋଇଥାଏ।
- କୌଣସି ଆକାଉଣ୍ଟ୍ ବିନା ପ୍ରକାଶ କରନ୍ତୁ। ଏକ ମ୍ୟାପ ପଏଣ୍ଟ୍ ବାଛନ୍ତୁ କିମ୍ବା coordinates ରେଖନ୍ତୁ; ଯେଉଁ listings ରେ coordinates ନାହିଁ, ସେଗୁଡିକ ଅନ୍ୱେଷଣ କରିବାକୁ ଉପଲବ୍ଧ ରହିବ।
- ଏକ ଲିଷ୍ଟିଂକୁ ସମ୍ପାଦନ କରନ୍ତୁ କିମ୍ବା ତାହାର ବ୍ୟକ୍ତିଗତ ଲିଙ୍କ ସହିତ ଡିଲିଟ୍ କରନ୍ତୁ। ଭର୍ସନ୍ ଯାଞ୍ଚ ଅଲଗା ଅଲଗା ଟ୍ୟାବରେ ସଙ୍କଟକାରୀ ସମ୍ପାଦନରୁ ରକ୍ଷା କରେ।
- ପ୍ରକାଶ କରିବା ପୂର୍ବରୁ ଥିବା ସ୍ତୁଡିଓଗୁଡ଼ିକୁ ଖୋଜିପାରିବେ। ସଠିକ୍ ନାମ, ସହର ଏବଂ ଠିକଣା ଯଦି ଦୁଇଟି ଥାଏ, ତେବେ ସେଗୁଡ଼ିକୁ ସ୍ବୟଂଚାଳିତ ଭାବରେ ବାତିଲ କରାଯିବ।
- ଉତ୍ସର ଆଧାର ସହିତ କ୍ୟାଟାଲଗ ଆମଦାନ କରନ୍ତୁ। ଅପରେଟରଙ୍କ ଦ୍ୱାରା କରାଯାଇଥିବା ଆମଦାନୀ ସ୍ୱୟଂ-ପ୍ରକାଶିତ ଲିଷ୍ଟିଂକୁ ଅତିରିକ୍ତ କରିବ ନାହିଁ।
- ଏକ API କି ବିନା OpenStreetMapଟିଲ ଦେଖନ୍ତୁ। ମ୍ୟାପ ପ୍ରଦର୍ଶିତ ହେବା ସମୟରେ, ଡିଫଲ୍ଟ ଲ୍ୟାଣ୍ଡିଂ ପେଜ ସହିତ, ଟିଲସ ଲୋଡ୍ ହୋଇଥାଏ।
- ଭାଷା ମେନୁରୁ ଇଣ୍ଟରଫେସ୍ ଭାଷାଟିକୁ ଚୟନ କରନ୍ତୁ। ଉପରକୁ ଦେଇଥିବା ଭାଷା ସୂଚି ମାଧ୍ୟମରେ ଆପଣଙ୍କ ଭାଷାରେ ପୂର୍ଣ୍ଣ README ପଢନ୍ତୁ।

ପ୍ରକାଶନ ବ୍ୟବସାୟିକ ମାଲିକାନାଧିକାର କିମ୍ବା ସେବାର ଗୁଣବତ୍ତା ଯାଞ୍ଚ କରେ ନାହିଁ। ସ୍ତୁଡ଼ିଓଠାରୁ ଯନ୍ତ୍ରପାତି, ସମର୍ଥତା ଏବଂ ନିୟମାବଳୀ ଯାଞ୍ଚ କରନ୍ତୁ। ଯେ କେହି ବ୍ୟକ୍ତି ଏକାଧିକାରୀ ପ୍ରବନ୍ଧନ ଲିଙ୍କକୁ ଧାରଣ କରିଛନ୍ତି, ସେହି ଲିଷ୍ଟିଂକୁ ନିୟନ୍ତ୍ରଣ କରିପାରିବେ। ଏହାକୁ ଗୋପନୀୟ ରଖନ୍ତୁ; ଏଥିରେ ଇମେଲ ପୁନଃପ୍ରାପ୍ତ କରିବାର କୌଣସି ବ୍ୟବସ୍ଥା ନାହିଁ। [ସ୍ୱ-ପ୍ରକାଶନ ମାର୍ଗଦର୍ଶିକା](../../docs/OPEN_CATALOG.md) ପଢ଼ନ୍ତୁ।

## ଆପଣଙ୍କର ପରିଚାଳନାଧୀନ ଅଧିକାରରେ ଏହା ଚଲାନ୍ତୁ

Node.js 24 ସ୍ଥାପନ କରନ୍ତୁ, ଏହି ରିପୋଜିଟୋରୀକୁ କ୍ଲୋନ କରନ୍ତୁ ଏବଂ ଚଲାନ୍ତୁ:

```sh
npm ci
npm run build
cp .env.example .env
npm start
```

Open `http://localhost:3000`। ଅନୁମତିପ୍ରାପ୍ତ `APP_MODE=catalog` ପାଇଁ କୌଣସି ପ୍ରଶାସକ କିମ୍ବା ବ୍ୟବହାରକାରୀ ସେଟଅପ୍ ଆବଶ୍ୟକ ନୁହେଁ। `APP_URL`, HTTPS ଏବଂ ବ୍ୟାକଅପ୍ ତିଆରି କରିବା ପାଇଁ [ସ୍ୱ-ହୋଷ୍ଟିଂ ଗାଇଡ୍](../../docs/SELF_HOSTING.md) ବ୍ୟବହାର କରନ୍ତୁ। Docker କମ୍ପୋଜ୍ ମଧ୍ୟ ଉପଲବ୍ଧ: `docker compose up --build -d`।

ସମର୍ଥିତ ଡିପ୍ଲୟମେଣ୍ଟ ହେଉଛି SQLite ସହିତ ଏକ ଲୋକାଲ୍ ଡିସ୍କରେ ଏକ ଆପ୍ଲିକେଶନ ପ୍ରକ୍ରିୟା। ସ୍ୱୟଂଚାଳିତ ପ୍ରକାଶନ ଏବଂ ଅନୁରୋଧ କୋଟା ମଧ୍ୟସ୍ଥତା କ୍ୟୁ ବିନା ଦୁର୍ବ୍ୟବହାରକୁ ସୀମିତ କରେ। ଏକ ସାମୂହିକ ଅଫିସ୍ IP ଏକ ପ୍ରକାଶନ କୋଟାକୁ ସାମଗ୍ରିକ ଭାବେ ବ୍ୟବହାର କରିପାରେ। ଜନସାଧାରଣ ଇନ୍‌ଷ୍ଟାନ୍ସ ଖୋଲିବା ପୂର୍ବରୁ [ସୀମା ଏବଂ ପରିଚାଳନା-ଲିଙ୍କ୍ ବ୍ୟବହାର](../../docs/OPEN_CATALOG.md) ଦେଖନ୍ତୁ।

ବିଦ୍ୟମାନ ତଥ୍ୟସମୂହର ଅଧିକାର ଯାଞ୍ଚ କରିବା ପରେ [କ୍ୟାଟାଲଗ୍ ଆମଦାନି CLI](../../docs/CATALOG_IMPORT.md) ବ୍ୟବହାର କରନ୍ତୁ। ନିଜ ସ୍ଥାପନର ତଥ୍ୟସମୂହ, ଅପଲୋଡ୍ ଏବଂ ବ୍ୟାକଅପ୍ ରିପୋଜିଟୋରି କିମ୍ବା କଣ୍ଟେନର ଇମେଜରେ ଅନ୍ତର୍ଭୁକ୍ତ ନୁହେଁ।

## ଅପ୍ସନାଲ୍ ସାମାଜିକ ଗୋଷ୍ଠୀ ଏବଂ Neofab ମୋଡ୍

ପ୍ରାଇଭେଟ ପ୍ରୋଜେକ୍ଟ, ପ୍ରୋଭାଇଡର କୋଟେସନ୍, ମଡେଲ ଲାଇବ୍ରେରୀ ଏବଂ Neofab ସ୍ଟୁଡିଓକୁ ସକ୍ରିୟ କରିବା ପାଇଁ `APP_MODE=community`କୁ ସ୍ପଷ୍ଟ ଭାବରେ ସେଟ୍ କରନ୍ତୁ। ଏହି ୱାର୍କଫ୍ଲୋଗୁଗୁ ତାଙ୍କର ନିଜ ଆକାଉଣ୍ଟ ଏବଂ ଅଧିକାର ବ୍ୟବହାର କରେ। ମୋଡ୍ ବଦଳାଇଲେ ସଞ୍ଚୟିତ ଡାଟା ଅକ୍ଷୁଣ୍ଣ ରହିବ। କ୍ୟାଟାଲଗ୍ ମୋଡ୍ ତାଙ୍କ API ମାଧ୍ୟମରେ ବ୍ୟକ୍ତିଗତ ସାମାଜିକ ଇତିହାସକୁ ପ୍ରକାଶ କରେ ନାହିଁ, ତଥା queued CAD କାର୍ଯ୍ୟକୁ ପୁନଃ ଆରମ୍ଭ କରେ ନାହିଁ।

[Neofab Studio](../../docs/NEOFAB_SETUP.md) ସଂସ୍କରଣ ସହିତ ନିର୍ମାଣ ଆବଶ୍ୟକତାପତ୍ର, ସାମଗ୍ରୀର ତାଲିକା ଏବଂ STEP/STL ରପ୍ତାନି ସହିତ ସୀମିତ ଘୋଷଣାମୂଳକ CAD ସମର୍ଥନ କରେ। CAD ଏବଂ AI ଇଚ୍ଛାଧୀନ। AI ପ୍ରସ୍ତାବକୁ ସମୀକ୍ଷା କରି ପୃଥକ ଭାବେ ପ୍ରୟୋଗ କରିବା ଆବଶ୍ୟକ; ଏଗୁଡ଼ିକ ସ୍ୱୟଂକ୍ରିୟ ଭାବେ ଅର୍ଡର ପ୍ରକାଶ କରେ ନାହିଁ କିମ୍ବା ଜ୍ୟାମିତି ନିର୍ମାଣ କରେ ନାହିଁ। CAM, G-code ଏବଂ ବାସ୍ତବ ନିର୍ମାଣର ଉପଯୋଗିତା ଯାଞ୍ଚ କାର୍ଯ୍ୟକାରୀ ହୋଇନାହିଁ।

## ତଥ୍ୟ ଅଧିକାର ଏବଂ ଗୋପନୀୟତା

MIT ସଫ୍ଟୱେର୍ ଲାଇସେନ୍ସ ଆମଦାନି କରାଯାଇଥିବା ବ୍ୟବସାୟ ତଥ୍ୟ ଉପରେ ଅଧିକାର ଦିଏ ନାହିଁ। କେବଳ ଉତ୍ସ ଉଲ୍ଲେଖ କଲେ Google Maps, 2GIS, Yandex Maps କିମ୍ବା ଅନ୍ୟ ଉତ୍ସର ତଥ୍ୟ ନକଲ କରିବାର ଅନୁମତି ମିଳେ ନାହିଁ। ତଥ୍ୟସମୂହ ବ୍ୟବହାର ପୂର୍ବରୁ ସଂରକ୍ଷଣ, ପ୍ରକାଶନ ଏବଂ ପୁନଃବିତରଣ ପାଇଁ ଅନୁମତି ଯାଞ୍ଚ କରନ୍ତୁ। [ତଥ୍ୟର ଉତ୍ସ ଏବଂ ସମୀକ୍ଷାର ସୀମା](../../docs/DATA_PROVENANCE.md) ଦେଖନ୍ତୁ।

ସ୍ୱୟଂ ପ୍ରକାଶିତ ସମ୍ପର୍କ ବିବରଣୀ ସର୍ବସାଧାରଣ; ପରିଚାଳନା କୁଞ୍ଜିଗୁଡ଼ିକ ଗୋପନୀୟ। ସର୍ବସାଧାରଣ ଭାବେ ବ୍ୟବହୃତ ହେଉଥିବା ଡିରେକ୍ଟରୀରୁ ଡାଟାବେସ୍ ଏବଂ ବ୍ୟାକଅପକୁ ଦୂରେ ରଖନ୍ତୁ, ଏବଂ ସଂଶୋଧନ ଏବଂ ଅବଲମ୍ବନ ଅନୁରୋଧ ପାଇଁ ଏକ ସମ୍ପର୍କ ପ୍ରଦାନ କରନ୍ତୁ। ଉପଯୋଗ କରିବା ପୂର୍ବରୁ [ଗୋପନୀୟତା](../../PRIVACY.md) ଏବଂ [ସୁରକ୍ଷା](../../SECURITY.md) ପଢ଼ନ୍ତୁ।

## ବିକାଶ ଏବଂ ଅନୁବାଦ

```sh
npm run dev
npm run check
npx playwright install chromium
npm run test:e2e
npm run format:check
```

GitHub କାର୍ଯ୍ୟଗୁଡ଼ିକ ପ୍ରକାର, API ଏବଂ ବ୍ରାଉଜର କାର୍ଯ୍ୟପ୍ରବାହ, ଏବଂ ଡିଫଲ୍ଟ ଏବଂ ପ୍ରାକୃତିକ CAD କଣ୍ଟେନରଗୁଡ଼ିକ ଯାଞ୍ଚ କରେ। ପରୀକ୍ଷଣରେ କଳ୍ପନାତ୍ମକ ରେକର୍ଡ୍ ବ୍ୟବହାର କରାୟାଏ। ସଠିକ୍ ପ୍ରମାଣ, କଭରେଜ ଏବଂ ଅବଶିଷ୍ଟ ସୀମା [ଭାଲିଡେସନ୍](../../docs/VALIDATION.md) ଏବଂ [ଉତ୍ପାଦ ଆୟତ୍ତ](../../docs/PRODUCT.md)ରେ ରେକର୍ଡ କରାୟାଏ।

ପୂର୍ଣ୍ଣ ଅନୁବାଦିତ ସଂସ୍କରଣ ପାଇଁ ଇଂରାଜୀରେ ଥିବା README ଏହାକୁ ସନ୍ଦର୍ଭ ଭାବରେ ବ୍ୟବହାର କରାଯାଇଥାଏ। [ଭାଷା ସୂଚିପତ୍ର](../../docs/i18n/README.md) ଅନୁବାଦର ରକ୍ଷଣାବେକ୍ଷଣ ଏବଂ ସମୀକ୍ଷା ସୀମା ବିଷୟରେ ତଥ୍ୟ ପ୍ରଦାନ କରେ। ଇଣ୍ଟରଫେସ୍ ଲୋକାଲାଇଜେସନ୍ ବ୍ୟବହାରକାରୀଙ୍କ ଦ୍ୱାରା ତିଆରି କରାଯାଇଥିବା ତାଲିକା, ପ୍ରକଳ୍ପର ବିଷୟବସ୍ତୁ କିମ୍ବା ପ୍ରତ୍ୟେକ ବାହ୍ୟ ବୈଷୟିକ ବିଶ୍ଲେଷଣକୁ ଅନୁବାଦ କରେ ନାହିଁ।

## ଲାଇସେନ୍ସ ଏବଂ ଅବଦାନ

ମୂଳ ସ୍ରୋତ, UI, SVG ଚିତ୍ର, ଦସ୍ତାବେଜ ଏବଂ ପାରାମେଟ୍ରିକ ଜେନେରେଟର [MIT ଅଧିକାର ଅଧୀନରେ](../../LICENSE) ରହିବ। ଅଧୀନତାଗୁଡ଼ିକ ସେମାନଙ୍କର ଅଲଗା ଅଧିକାର ଏବଂ ସୂଚନାକୁ ଅକ୍ଷୁଣ୍ଣ ରଖିବ। ବ୍ୟବହାରକାରୀଙ୍କ ମଡେଲଗୁଡ଼ିକର ଏକ ଅଲଗା ଅଧିକାର ରହିଛି, ଯାହା ସେମାନଙ୍କ ଲେଖକଙ୍କ ଦ୍ୱାରା ଚୟନ କରାଯାଇଛି। କଳ୍ପନାତ୍ମକ ଡେମୋ ପ୍ରୋଫାଇଲ ଏବଂ ସଂକ୍ଷିପ୍ତ ଲେଖା, ଏବଂ ତିନୋଟି ଉତ୍ପାଦିତ ଡେମୋ ଡିଜାଇନ୍, CC0 ଅଧୀନରେ ଉପଲବ୍ଧ; ଜେନେରେଟର MIT ରହିବ। [ତୃତୀୟ-ପକ୍ଷ ସୂଚନା](../../THIRD_PARTY_NOTICES.md) ଦେଖନ୍ତୁ।

ଏହି ସ୍ୱତନ୍ତ୍ର ପ୍ରୟୋଗ [3d-online.app](https://3d-online.app) ର ଧାରଣାକୁ ଆଗକୁ ନେଇଯାଏ। ମୂଳ ପ୍ରୋଡକ୍ସନ୍ ଆକାଉଣ୍ଟ, ଗୁପ୍ତ ସୂଚନା, ବ୍ୟକ୍ତିଗତ ଗିଟ୍ ଇତିହାସ ଏବଂ ବ୍ୟବହାରକାରୀଙ୍କ ଫାଇଲ୍ ସମେତ ନଥାନ୍ତି। ଅନୁରୂପ MIT Neofab CAD କମ୍ପାଇଲର ତା’ର [ମୂଳ ଲାଇସେନ୍ସ ଏବଂ ଉତ୍ପତ୍ତି ସୂଚନା](../../cad-worker/NOTICE.md) ଉପରେ ଅଧିକାର ରଖିଥାଏ।

ଅଂଶଦାନରେ କୋଡ, ଅନୁବାଦ ସଂଶୋଧନ, ବ୍ୟବହାରିତାକୁ ସୁଧାରିବା, ଖୋଲା ପାରାମେଟ୍ରିକ ଅଂଶ, ସ୍ଥାପନା ଯାଞ୍ଚ ଏବଂ ପ୍ରକୃତ କାରଖାନାମାନଙ୍କଠାରୁ ପ୍ରତିକ୍ରିୟା ସାମିଲ କରାଯାଇପାରେ। [CONTRIBUTING.md](../../CONTRIBUTING.md) ସହିତ ଆରମ୍ଭ କରନ୍ତୁ।
