אתרו סדנה במפה, בדקו את היכולות שלה וצרו איתם קשר ישירות. אם הסדנה שלכם חסרה, הוסיפו את פרטי הקשר והשירותים שלה: הרשומה תופיע באופן מיידי. שמרו את קישור הניהול הפרטי כדי לערוך או למחוק את הרשומה שלכם בהמשך. בקטלוג הראשי אין חשבונות, אישור בדוא"ל או תור המתנה לאישור.

הפעל את OpenPrint עם Node.js 24 ואת SQLite המקומי. Vercel, Supabase, ספק שירותי דואר אלקטרוני, בינה מלאכותית בתשלום וכניסה באמצעות צד שלישי אינם נדרשים. GitHub מארח את קוד המקור ואת הגרסאות; אתר משותף המקבל תרומות זקוק לשרת API פעיל. [GitHub עמודים](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) לבדם אינם יכולים להפעיל את Node.js API או לשמור שינויים של מבקרים.

## תכונות הקטלוג

- [רשת סדנאות](../../docs/WORKSHOP_NETWORK.md). ההזמנה והקובץ שלך יישמרו בצומת של הסדנה שבחרת.
- חפש לפי שם, עיר וטכנולוגיה. המפה כוללת מיקומים תואמים, ללא תלות בעמודים ברשימה.
- פרסם ללא צורך בחשבון. בחר נקודה במפה או הזן קואורדינטות; רשומות ללא קואורדינטות עדיין ניתנות לחיפוש.
- ערוך או מחק רשומה אחת, כולל הקישור הפרטי שלה. בדיקות גרסה מונעות עריכות סותרות בכרטיסיות שונות.
- אתרו סטודיו קיים לפני פרסום. שמות, ערים וכתובות זהות נדחים באופן אוטומטי.
- ייבא קטלוג עם ציון מקור המידע. משתמשים לא יכולים לדרוס רשומות שפורסמו על ידם.
- הצג OpenStreetMap אריחים ללא API מפתח. האריחים נטענים כאשר מוצגת מפה, כולל דף הבית המוגדר כברירת מחדל.
- בחרו את שפת הממשק מתפריט השפות. קראו את קובץ ה-README המלא בשפתכם דרך מדריך השפות שלמעלה.

פרסום אינו מאמת בעלות על העסק או את איכות השירות. ודאו את הציוד, היכולות והתנאים מול הסטודיו. כל מי שמחזיק בקישור הניהול הפרטי יכול לשלוט ברשימה זו. שמרו עליו בסודיות; אין אפשרות לשחזר אותו באמצעות דוא"ל. קראו את [מדריך הפרסום העצמי](../../docs/OPEN_CATALOG.md).

## הפעל את המופע שלך

התקינו את Node.js 24, שכפלו את המאגר הזה והריצו:

```sh
npm ci
npm run build
cp .env.example .env
npm start
```

Open `http://localhost:3000`. הגדרות ברירת המחדל `APP_MODE=catalog` אינן דורשות הגדרה מצד מנהל מערכת או משתמש. הגדירו את `APP_URL`, HTTPS ואת הגיבויים באמצעות [מדריך ההתקנה העצמאית](../../docs/SELF_HOSTING.md). Docker Compose זמין גם הוא: `docker compose up --build -d`.

הפריסה הנתמכת היא תהליך אפליקציה אחד עם SQLite בדיסק מקומי. פרסום אוטומטי ומגבלות על מספר הבקשות מגבילים שימוש לרעה ללא צורך בתור ניטור. כתובת IP משותפת למשרד יכולה לחלוק מכסת פרסומים. עיינו ב[מגבלות והתנהגות ניהול](../../docs/OPEN_CATALOG.md) לפני פתיחת מופע ציבורי.

השתמשו ב[כלי ייבוא הקטלוג בשורת הפקודה](../../docs/CATALOG_IMPORT.md) עבור מערך נתונים קיים, לאחר בדיקת זכויות השימוש בו. מערכי נתונים של מופע מסוים, קבצים שהועלו וגיבויים אינם נכללים במאגר או בתמונות הקונטיינר.

## אפשרות לקהילה ומצב Neofab

הגדירו את `APP_MODE=community` במפורש כדי לאפשר פרויקטים פרטיים, הצעות מחיר מספקים, ספריית המודלים ו-Neofab Studio. זרימות העבודה הללו משתמשות בחשבונות והרשאות משלהן. מעבר בין מצבים שומר על הנתונים השמורים. במצב קטלוג, היסטוריה פרטית של הקהילה אינה נחשפת דרך ה-API שלו, וכן לא מתחדשת עבודה בתור CAD.

[Neofab Studio](../../docs/NEOFAB_SETUP.md) תומך במסמכי דרישות לייצור עם ניהול גרסאות, ברשימות חומרים וב-CAD הצהרתי בעל מגבלות מוגדרות, עם ייצוא ל-STEP/STL. CAD ובינה מלאכותית הם רכיבים אופציונליים. הצעות של בינה מלאכותית דורשות בדיקה ושלב יישום נפרד; הן אינן מפרסמות הזמנות או בונות גאומטריה באופן אוטומטי. CAM, קוד G ואימות פיזי של הייצור אינם ממומשים.

## זכויות נתונים ופרטיות

רישיון התוכנה MIT אינו מעניק זכויות לנתונים עסקיים מיובאים. ציון מקור בלבד אינו מאפשר העתקת נתונים מ-Google Maps, 2GIS, Yandex Maps או ממקורות אחרים. ודאו את ההרשאות לאחסון, פרסום והפצה מחדש לפני השימוש במערך נתונים. ראו [מקור הנתונים וגבולות הבדיקה](../../docs/DATA_PROVENANCE.md).

פרטי יצירת קשר שפורסמו באופן עצמאי הם ציבוריים; מפתחות ניהול הם פרטיים. שמרו על מסדי נתונים וגיבויים מחוץ לספריות הנגישות לציבור, וספקו איש קשר לתיקונים ולבקשות להסרה. קראו את [מדיניות הפרטיות](../../PRIVACY.md) ואת [מדיניות האבטחה](../../SECURITY.md) לפני הפריסה.

## פיתוח ותרגום

```sh
npm run dev
npm run check
npx playwright install chromium
npm run test:e2e
npm run format:check
```

GitHub הפעולות בודקות סוגים, API וזרימות עבודה בדפדפן, וכן את המכולות המוגדרות כברירת מחדל והמקוריות CAD. הבדיקות משתמשות ברשומות פיקטיביות. ראיות מדויקות, היקף הבדיקה ומגבלות שנותרו מתועדים ב-[אימות](../../docs/VALIDATION.md) וב-[היקף המוצר](../../docs/PRODUCT.md).

קובץ ה-README באנגלית משמש כמקור המידע עבור כל הגרסאות המתורגמות. [מדריך השפות](../../docs/i18n/README.md) מתעד את מגבלות התחזוקה והבדיקה של התרגום. התאמת הממשק לשפה מסוימת אינה כוללת תרגום של רשימות שנוצרו על ידי משתמשים, תוכן הפרויקט או כל בדיקה טכנית חיצונית.
