Εντοπίστε ένα εργαστήριο στον χάρτη, ελέγξτε τις δυνατότητές του και επικοινωνήστε απευθείας μαζί του. Εάν το εργαστήριό σας δεν εμφανίζεται, προσθέστε τα στοιχεία επικοινωνίας και τις υπηρεσίες του: η καταχώρηση θα εμφανιστεί αμέσως. Αποθηκεύστε τον ιδιωτικό σύνδεσμο διαχείρισης για να επεξεργαστείτε ή να διαγράψετε την καταχώρησή σας αργότερα. Ο προεπιλεγμένος κατάλογος δεν περιέχει λογαριασμούς, επιβεβαίωση μέσω email ή λίστα αναμονής για έγκριση.

Εκτελέστε το OpenPrint με το Node.js 24 και το τοπικό SQLite. Δεν απαιτούνται το Vercel, το Supabase, ένας πάροχος ηλεκτρονικού ταχυδρομείου, η πληρωμένη τεχνητή νοημοσύνη και η σύνδεση μέσω τρίτων. Το GitHub φιλοξενεί τον πηγαίο κώδικα και τις εκδόσεις· ένας κοινός ιστότοπος που δέχεται υποβολές χρειάζεται έναν ενεργό διακομιστή API. Οι [GitHub Σελίδες](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) από μόνες τους δεν μπορούν να εκτελέσουν το Node.js API ή να διατηρήσουν τις αλλαγές των επισκεπτών.

## Χαρακτηριστικά καταλόγου

- [Δίκτυο εργαστηρίων](../../docs/WORKSHOP_NETWORK.md). Η παραγγελία και το αρχείο σας θα αποθηκευτούν στον κόμβο του εργαστηρίου που επιλέξατε.
- Αναζητήστε κατά όνομα, πόλη και τεχνολογία. Ο χάρτης περιλαμβάνει τις αντίστοιχες τοποθεσίες, ανεξάρτητα από τη σελιδοποίηση της λίστας.
- Δημοσιεύστε χωρίς να δημιουργήσετε λογαριασμό. Επιλέξτε ένα σημείο στον χάρτη ή εισαγάγετε συντεταγμένες· οι καταχωρήσεις χωρίς συντεταγμένες παραμένουν διαθέσιμες για αναζήτηση.
- Επεξεργαστείτε ή διαγράψτε μία καταχώρηση μαζί με τον ιδιωτικό σύνδεσμό της. Οι έλεγχοι έκδοσης προστατεύουν από πιθανές συγκρούσεις κατά την επεξεργασία σε διαφορετικές καρτέλες.
- Εντοπίστε υπάρχοντα στούντιο πριν από τη δημοσίευση. Οι ακριβείς διπλότυπες εγγραφές ονόματος, πόλης και διεύθυνσης απορρίπτονται αυτόματα.
- Εισαγάγετε έναν κατάλογο με αναφορά στην πηγή. Οι εισαγωγές από τον διαχειριστή δεν μπορούν να αντικαταστήσουν τις καταχωρήσεις που έχουν υποβληθεί απευθείας από τους χρήστες.
- Προβάλετε OpenStreetMap πλακίδια χωρίς να χρειάζεται API κλειδί. Τα πλακίδια φορτώνονται όταν εμφανίζεται ένας χάρτης, συμπεριλαμβανομένης της προεπιλεγμένης αρχικής σελίδας.
- Επιλέξτε τη γλώσσα διεπαφής από το μενού γλωσσών. Διαβάστε ολόκληρο το αρχείο README στη γλώσσα σας μέσω του παραπάνω ευρετηρίου γλωσσών.

Η δημοσίευση δεν επιβεβαιώνει την ιδιοκτησία της επιχείρησης ή την ποιότητα των παρεχόμενων υπηρεσιών. Επιβεβαιώστε τον εξοπλισμό, τις δυνατότητες και τους όρους απευθείας με το στούντιο. Οποιοσδήποτε κατέχει τον ιδιωτικό σύνδεσμο διαχείρισης μπορεί να ελέγξει την συγκεκριμένη καταχώρηση. Διατηρήστε τον ιδιωτικό· δεν υπάρχει δυνατότητα ανάκτησης μέσω email. Διαβάστε τον [οδηγό αυτοδημοσίευσης](../../docs/OPEN_CATALOG.md).

## Εκτελέστε τη δική σας εγκατάσταση

Εγκαταστήστε το Node.js 24, κλωνοποιήστε αυτό το αποθετήριο και εκτελέστε:

```sh
npm ci
npm run build
cp .env.example .env
npm start
```

Open `http://localhost:3000`. Η προεπιλεγμένη `APP_MODE=catalog` δεν απαιτεί διαμόρφωση από διαχειριστή ή χρήστη. Διαμορφώστε τις `APP_URL`, HTTPS και τις δημιουργίες αντιγράφων ασφαλείας χρησιμοποιώντας τον [οδηγό αυτοφιλοξενίας](../../docs/SELF_HOSTING.md). Docker Το Compose είναι επίσης διαθέσιμο: `docker compose up --build -d`.

Η υποστηριζόμενη μέθοδος εγκατάστασης περιλαμβάνει μία διαδικασία εφαρμογής με SQLite σε έναν τοπικό δίσκο. Η αυτόματη δημοσίευση και τα όρια αιτημάτων περιορίζουν την κατάχρηση χωρίς την ανάγκη ουράς εποπτείας. Μια κοινόχρηστη διεύθυνση IP μπορεί να μοιραστεί ένα όριο δημοσίευσης. Ανατρέξτε στο [όρια και συμπεριφορά συνδέσμου διαχείρισης](../../docs/OPEN_CATALOG.md) πριν ανοίξετε μια δημόσια παρουσία.

Χρησιμοποιήστε το εργαλείο γραμμής εντολών [εισαγωγής καταλόγου](../../docs/CATALOG_IMPORT.md) για ένα υπάρχον σύνολο δεδομένων, αφού ελέγξετε τα δικαιώματά του. Τα σύνολα δεδομένων, οι μεταφορτώσεις και τα αντίγραφα ασφαλείας δεν περιλαμβάνονται στο αποθετήριο ή στις εικόνες κοντέινερ.

## Προαιρετική λειτουργία κοινότητας και Neofab

Ορίστε την παράμετρο `APP_MODE=community` σε συγκεκριμένη τιμή για να ενεργοποιήσετε τις ιδιωτικές εργασίες, τις προσφορές των παρόχων, τη βιβλιοθήκη μοντέλων και το Neofab Studio. Αυτές οι ροές εργασίας χρησιμοποιούν τους δικούς τους λογαριασμούς και δικαιώματα. Η αλλαγή λειτουργίας διατηρεί τα αποθηκευμένα δεδομένα. Η λειτουργία καταλόγου δεν αποκαλύπτει το ιδιωτικό ιστορικό της κοινότητας μέσω του API της, ούτε συνεχίζει τις εκκρεμείς CAD εργασίες.

[Neofab Studio](../../docs/NEOFAB_SETUP.md) υποστηρίζει εκδόσεις εγγράφων προδιαγραφών κατασκευής, καταλόγους υλικών και οριοθετημένη δηλωτική CAD με εξαγωγές σε STEP/STL. Η CAD και η τεχνητή νοημοσύνη είναι προαιρετικές. Οι προτάσεις που βασίζονται στην τεχνητή νοημοσύνη απαιτούν έλεγχο και μια ξεχωριστή διαδικασία υποβολής αίτησης· δεν δημοσιεύουν αυτόματα παραγγελίες ούτε δημιουργούν γεωμετρίες. Η CAM, ο κώδικας G και η φυσική επικύρωση της κατασκευής δεν έχουν υλοποιηθεί.

## Δικαιώματα δεδομένων και προστασία της ιδιωτικότητας

Η άδεια χρήσης του λογισμικού MIT δεν παρέχει δικαιώματα για τα εισαγόμενα επιχειρηματικά αρχεία. Η απλή αναφορά της πηγής δεν επιτρέπει την αντιγραφή δεδομένων από τους χάρτες Google, την 2GIS, την Yandex Maps ή άλλες πηγές. Ελέγξτε τα δικαιώματα για την αποθήκευση, τη δημοσίευση και την αναδιανομή πριν χρησιμοποιήσετε ένα σύνολο δεδομένων. Δείτε [όρια προέλευσης και ελέγχου δεδομένων](../../docs/DATA_PROVENANCE.md).

Οι πληροφορίες επικοινωνίας που δημοσιεύονται από τον χρήστη είναι δημόσιες· τα κλειδιά διαχείρισης είναι ιδιωτικά. Διατηρήστε τις βάσεις δεδομένων και τα αντίγραφα ασφαλείας εκτός των καταλόγων που είναι προσβάσιμοι στο κοινό και παρέχετε ένα σημείο επικοινωνίας για αιτήματα διόρθωσης και διαγραφής. Διαβάστε τις ενότητες [προστασίας προσωπικών δεδομένων](../../PRIVACY.md) και [ασφάλειας](../../SECURITY.md) πριν από την εφαρμογή.

## Ανάπτυξη και μετάφραση

```sh
npm run dev
npm run check
npx playwright install chromium
npm run test:e2e
npm run format:check
```

GitHub Οι ενέργειες ελέγχουν τους τύπους, API και τις ροές εργασίας του προγράμματος περιήγησης, καθώς και τα προεπιλεγμένα και εγγενή CAD περιβάλλοντα. Οι δοκιμές χρησιμοποιούν υποθετικά αρχεία. Οι ακριβείς αποδείξεις, η κάλυψη και τα υπόλοιπα όρια καταγράφονται στην ενότητα [ελέγχου εγκυρότητας](../../docs/VALIDATION.md) και στην ενότητα [πεδίου εφαρμογής του προϊόντος](../../docs/PRODUCT.md).

Το αγγλικό αρχείο README αποτελεί την πηγή αναφοράς για τις πλήρεις μεταφρασμένες εκδόσεις. Ο [πίνακας γλωσσών](../../docs/i18n/README.md) περιέχει πληροφορίες σχετικά με τη συντήρηση των μεταφράσεων και τα όρια των ελέγχων. Η προσαρμογή της διεπαφής δεν μεταφράζει τις καταχωρήσεις που έχουν δημιουργήσει οι χρήστες, το περιεχόμενο των έργων ή κάθε εξωτερικό τεχνικό έγγραφο διαγνωστικού ελέγχου.
