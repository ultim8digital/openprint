ਮੈਪ 'ਤੇ ਇੱਕ ਨਿਰਮਾਤਾ ਲੱਭੋ, ਉਹਨਾਂ ਦੀਆਂ ਸਮਰੱਥਾਵਾਂ ਦੀ ਜਾਂਚ ਕਰੋ ਅਤੇ ਉਹਨਾਂ ਨਾਲ ਸਿੱਧਾ ਸੰਪਰਕ ਕਰੋ। ਜੇਕਰ ਤੁਹਾਡੀ ਵਰਕਸ਼ਾਪ ਦੀ ਜਾਣਕਾਰੀ ਨਹੀਂ ਹੈ, ਤਾਂ ਇਸਦੀ ਸੰਪਰਕ ਜਾਣਕਾਰੀ ਅਤੇ ਸੇਵਾਵਾਂ ਸ਼ਾਮਲ ਕਰੋ: ਜਾਣਕਾਰੀ ਤੁਰੰਤ ਦਿਖਾਈ ਦੇਵੇਗੀ। ਬਾਅਦ ਵਿੱਚ ਆਪਣੀ ਜਾਣਕਾਰੀ ਨੂੰ ਸੰਪਾਦਿਤ ਕਰਨ ਜਾਂ ਹਟਾਉਣ ਲਈ ਨਿੱਜੀ ਪ੍ਰਬੰਧਨ ਲਿੰਕ ਨੂੰ ਸੁਰੱਖਿਅਤ ਕਰੋ। ਡਿਫੌਲਟ ਕੈਟਾਲਾਗ ਵਿੱਚ ਕੋਈ ਖਾਤੇ, ਈਮੇਲ ਪੁਸ਼ਟੀਕਰਨ ਜਾਂ ਪ੍ਰਵਾਨਗੀ ਕਤਾਰ ਨਹੀਂ ਹੈ।

OpenPrint ਨੂੰ Node.js 24 ਅਤੇ ਸਥਾਨਕ SQLite ਨਾਲ ਚਲਾਓ। Vercel, Supabase, ਇੱਕ ਈਮੇਲ ਪ੍ਰਦਾਤਾ, ਪੇਡ AI ਅਤੇ ਤੀਜੀ ਧਿਰ ਦੁਆਰਾ ਲੌਗਇਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ। GitHub ਸਰੋਤ ਅਤੇ ਰੀਲੀਜ਼ਾਂ ਦੀ ਮੇਜ਼ਬਾਨੀ ਕਰਦਾ ਹੈ; ਇੱਕ ਸਾਂਝੀ ਵੈੱਬਸਾਈਟ ਜਿਸ ਵਿੱਚ ਸਮੱਗਰੀ ਜਮ੍ਹਾਂ ਕਰਵਾਈ ਜਾਂਦੀ ਹੈ, ਨੂੰ ਚੱਲ ਰਹੇ API ਸਰਵਰ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ। [GitHub ਪੇਜ](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) ਆਪਣੇ ਆਪ Node.js API ਨੂੰ ਨਹੀਂ ਚਲਾ ਸਕਦੇ ਅਤੇ ਨਾ ਹੀ ਦਰਸ਼ਕਾਂ ਦੁਆਰਾ ਕੀਤੇ ਗਏ ਬਦਲਾਵਾਂ ਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖ ਸਕਦੇ ਹਨ।

## ਕੈਟਾਲਾਗ ਦੀਆਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ

- [ਵਰਕਸ਼ਾਪ ਨੈੱਟਵਰਕ](../../docs/WORKSHOP_NETWORK.md). ਤੁਹਾਡਾ ਆਰਡਰ ਅਤੇ ਫਾਈਲ ਚੁਣੀ ਹੋਈ ਵਰਕਸ਼ਾਪ ਦੇ ਨੋਡ ਉੱਤੇ ਸੁਰੱਖਿਅਤ ਕੀਤੇ ਜਾਣਗੇ।
- ਨਾਮ, ਸ਼ਹਿਰ ਅਤੇ ਤਕਨਾਲੋਜੀ ਦੁਆਰਾ ਖੋਜ ਕਰੋ। ਨਕਸ਼ਾ, ਸੂਚੀ ਦੇ ਪੰਨਿਆਂ ਦੀ ਗਿਣਤੀ ਤੋਂ ਸੁਤੰਤਰ, ਮਿਲਦੇ-ਜੁਲਦੇ ਸਥਾਨਾਂ ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ।
- ਕਿਸੇ ਖਾਤੇ ਤੋਂ ਬਿਨਾਂ ਪ੍ਰਕਾਸ਼ਿਤ ਕਰੋ। ਇੱਕ ਨਕਸ਼ੇ 'ਤੇ ਬਿੰਦੂ ਚੁਣੋ ਜਾਂ ਕੋਆਰਡੀਨੇਟ ਦਰਜ ਕਰੋ; ਜਿਹੜੀਆਂ ਸੂਚੀਆਂ ਵਿੱਚ ਕੋਆਰਡੀਨੇਟ ਨਹੀਂ ਹਨ, ਉਹ ਖੋਜਣ ਯੋਗ ਰਹਿਣਗੀਆਂ।
- ਇੱਕ ਲਿਸਟਿੰਗ ਨੂੰ ਸੋਧੋ ਜਾਂ ਇਸਦੇ ਨਿੱਜੀ ਲਿੰਕ ਨਾਲ ਮਿਟਾਓ। ਵਰਜ਼ਨ ਦੀ ਜਾਂਚ ਵੱਖ-ਵੱਖ ਟੈਬਾਂ ਵਿੱਚ ਹੋਣ ਵਾਲੀਆਂ ਟਕਰਾਅ ਵਾਲੀਆਂ ਸੋਧਾਂ ਤੋਂ ਬਚਾਅ ਕਰਦੀ ਹੈ।
- ਪ੍ਰਕਾਸ਼ਿਤ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਮੌਜੂਦਾ ਸਟੂਡੀਓ ਲੱਭੋ। ਬਿਲਕੁਲ ਇੱਕੋ ਨਾਮ, ਸ਼ਹਿਰ ਅਤੇ ਪਤੇ ਵਾਲੇ ਦੁਹਰਾਏ ਗਏ ਰਿਕਾਰਡ ਆਪਣੇ ਆਪ ਰੱਦ ਕਰ ਦਿੱਤੇ ਜਾਣਗੇ।
- ਸਰੋਤ ਦਾ ਜ਼ਿਕਰ ਕਰਦੇ ਹੋਏ ਇੱਕ ਕੈਟਾਲਾਗ ਆਯਾਤ ਕਰੋ। ਆਪਰੇਟਰ ਦੁਆਰਾ ਕੀਤੀਆਂ ਆਯਾਤਾਂ, ਖੁਦ ਪ੍ਰਕਾਸ਼ਿਤ ਕੀਤੀਆਂ ਸੂਚੀਆਂ ਨੂੰ ਬਦਲ ਨਹੀਂ ਸਕਦੀਆਂ।
- OpenStreetMap ਕੁੰਜੀ ਤੋਂ ਬਿਨਾਂ API ਟਾਈਲਾਂ ਦੇਖੋ। ਜਦੋਂ ਕੋਈ ਨਕਸ਼ਾ ਦਿਖਾਇਆ ਜਾਂਦਾ ਹੈ, ਤਾਂ ਟਾਈਲਾਂ ਲੋਡ ਹੁੰਦੀਆਂ ਹਨ, ਜਿਸ ਵਿੱਚ ਡਿਫੌਲਟ ਲੈਂਡਿੰਗ ਪੇਜ ਵੀ ਸ਼ਾਮਲ ਹੈ।
- ਭਾਸ਼ਾ ਮੀਨੂ ਵਿੱਚੋਂ ਇੰਟਰਫੇਸ ਭਾਸ਼ਾ ਚੁਣੋ। ਉੱਪਰ ਦਿੱਤੇ ਭਾਸ਼ਾ ਇੰਡੈਕਸ ਰਾਹੀਂ ਆਪਣੀ ਭਾਸ਼ਾ ਵਿੱਚ ਪੂਰਾ README ਪੜ੍ਹੋ।

ਪ੍ਰਕਾਸ਼ਨ ਕਾਰੋਬਾਰ ਦੀ ਮਾਲਕੀ ਜਾਂ ਸੇਵਾ ਦੀ ਗੁਣਵੱਤਾ ਦੀ ਪੁਸ਼ਟੀ ਨਹੀਂ ਕਰਦਾ। ਸਟੂਡੀਓ ਨਾਲ ਉਪਕਰਣ, ਸਮਰੱਥਾਵਾਂ ਅਤੇ ਸ਼ਰਤਾਂ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ। ਜਿਹੜਾ ਵਿਅਕਤੀ ਨਿੱਜੀ ਪ੍ਰਬੰਧਨ ਲਿੰਕ ਰੱਖਦਾ ਹੈ, ਉਹ ਉਸ ਸੂਚੀ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰ ਸਕਦਾ ਹੈ। ਇਸਨੂੰ ਨਿੱਜੀ ਰੱਖੋ; ਇੱਥੇ ਕੋਈ ਈਮੇਲ ਰਿਕਵਰੀ ਨਹੀਂ ਹੈ। [ਸਵੈ-ਪ੍ਰਕਾਸ਼ਨ ਗਾਈਡ](../../docs/OPEN_CATALOG.md) ਪੜ੍ਹੋ।

## ਆਪਣੀ ਖੁਦ ਦੀ ਕਾਪੀ ਚਲਾਓ

Node.js 24 ਇੰਸਟਾਲ ਕਰੋ, ਇਸ ਰਿਪੋਜ਼ਟਰੀ ਨੂੰ ਕਲੋਨ ਕਰੋ ਅਤੇ ਚਲਾਓ:

```sh
npm ci
npm run build
cp .env.example .env
npm start
```

ਓਪਨ `http://localhost:3000`। ਡਿਫੌਲਟ `APP_MODE=catalog` ਲਈ ਕਿਸੇ ਪ੍ਰਸ਼ਾਸਕ ਜਾਂ ਉਪਭੋਗਤਾ ਸੈਟਅੱਪ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ। [ਸੈਲਫ-ਹੋਸਟਿੰਗ ਗਾਈਡ](../../docs/SELF_HOSTING.md) ਦੀ ਵਰਤੋਂ ਕਰਕੇ `APP_URL`, HTTPS ਅਤੇ ਬੈਕਅੱਪ ਨੂੰ ਕੌਂਫਿਗਰ ਕਰੋ। Docker ਕੰਪੋਜ਼ ਵੀ ਉਪਲਬਧ ਹੈ: `docker compose up --build -d`।

ਸਮਰਥਿਤ ਡਿਪਲੋਇਮੈਂਟ ਵਿੱਚ ਇੱਕ ਐਪਲੀਕੇਸ਼ਨ ਪ੍ਰਕਿਰਿਆ SQLite ਦੇ ਨਾਲ ਇੱਕ ਲੋਕਲ ਡਿਸਕ 'ਤੇ ਹੁੰਦੀ ਹੈ। ਆਪਣੇ ਆਪ ਪ੍ਰਕਾਸ਼ਨ ਅਤੇ ਬੇਨਤੀਆਂ ਦੀ ਸੀਮਾ, ਮੱਧਸਥੀ ਕਤਾਰ ਤੋਂ ਬਿਨਾਂ, ਦੁਰਵਰਤੋਂ ਨੂੰ ਸੀਮਤ ਕਰਦੀ ਹੈ। ਇੱਕ ਸਾਂਝਾ ਦਫ਼ਤਰ ਆਈਪੀ ਇੱਕ ਪ੍ਰਕਾਸ਼ਨ ਸੀਮਾ ਸਾਂਝਾ ਕਰ ਸਕਦਾ ਹੈ। ਇੱਕ ਪਬਲਿਕ ਉਦਾਹਰਣ ਖੋਲ੍ਹਣ ਤੋਂ ਪਹਿਲਾਂ [ਸੀਮਾਵਾਂ ਅਤੇ ਪ੍ਰਬੰਧਨ-ਲਿੰਕ ਵਿਵਹਾਰ](../../docs/OPEN_CATALOG.md) ਦੇਖੋ।

ਇਸਦੇ ਅਧਿਕਾਰਾਂ ਦੀ ਜਾਂਚ ਕਰਨ ਤੋਂ ਬਾਅਦ, ਮੌਜੂਦਾ ਡਾਟਾ ਸੈੱਟ ਲਈ [ਕੈਟਾਲਾਗ ਆਯਾਤ CLI](../../docs/CATALOG_IMPORT.md) ਦੀ ਵਰਤੋਂ ਕਰੋ। ਇੰਸਟੈਂਸ ਡਾਟਾ ਸੈੱਟ, ਅਪਲੋਡ ਅਤੇ ਬੈਕਅੱਪ ਰਿਪੋਜ਼ਟਰੀ ਜਾਂ ਕੰਟੇਨਰ ਚਿੱਤਰਾਂ ਵਿੱਚ ਸ਼ਾਮਲ ਨਹੀਂ ਹਨ।

## ਵਿਕਲਪਿਕ ਭਾਈਚਾਰਾ ਅਤੇ Neofab ਮੋਡ

ਨਿੱਜੀ ਪ੍ਰੋਜੈਕਟਾਂ, ਪ੍ਰਦਾਤਾਵਾਂ ਦੇ ਹਵਾਲੇ, ਮਾਡਲ ਲਾਇਬ੍ਰੇਰੀ ਅਤੇ Neofab ਸਟੂਡੀਓ ਨੂੰ ਸਮਰੱਥ ਕਰਨ ਲਈ `APP_MODE=community` ਨੂੰ ਸਪਸ਼ਟ ਤੌਰ 'ਤੇ ਸੈੱਟ ਕਰੋ। ਇਹ ਵਰਕਫਲੋ ਆਪਣੇ ਖੁਦ ਦੇ ਖਾਤਿਆਂ ਅਤੇ ਅਧਿਕਾਰਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹਨ। ਮੋਡ ਬਦਲਣ ਨਾਲ ਸਟੋਰ ਕੀਤੀ ਡਾਟਾ ਬਰਕਰਾਰ ਰਹਿੰਦੀ ਹੈ। ਕੈਟਾਲਾਗ ਮੋਡ ਇਸਦੇ API ਦੁਆਰਾ ਜਾਂ ਰੁਕੀ ਹੋਈ CAD ਕਾਰਵਾਈ ਨੂੰ ਦੁਬਾਰਾ ਸ਼ੁਰੂ ਕਰਕੇ ਨਿੱਜੀ ਕਮਿਊਨਿਟੀ ਦੇ ਇਤਿਹਾਸ ਨੂੰ ਪ੍ਰਗਟ ਨਹੀਂ ਕਰਦਾ।

[Neofab ਸਟੂਡੀਓ](../../docs/NEOFAB_SETUP.md) ਸੰਸਕਰਿਤ ਨਿਰਮਾਣ ਸੰਖੇਪਾਂ, ਸਮੱਗਰੀ ਦੀਆਂ ਸੂਚੀਆਂ ਅਤੇ ਸੀਮਿਤ ਘੋਸ਼ਣਾਤਮਕ CAD ਦਾ ਸਮਰਥਨ ਕਰਦਾ ਹੈ, ਜਿਸ ਵਿੱਚ STEP/STL ਐਕਸਪੋਰਟ ਸ਼ਾਮਲ ਹਨ। CAD ਅਤੇ AI ਵਿਕਲਪਿਕ ਹਨ। AI ਪ੍ਰਸਤਾਵਾਂ ਲਈ ਸਮੀਖਿਆ ਅਤੇ ਇੱਕ ਵੱਖਰੇ ਅਰਜ਼ੀ ਪੜਾਅ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ; ਇਹ ਆਪਣੇ ਆਪ ਆਰਡਰ ਪ੍ਰਕਾਸ਼ਿਤ ਨਹੀਂ ਕਰਦੇ ਜਾਂ ਜਿਓਮੈਟਰੀ ਨਹੀਂ ਬਣਾਉਂਦੇ। CAM, ਜੀ-ਕੋਡ ਅਤੇ ਭੌਤਿਕ ਨਿਰਮਾਣ ਦੀ ਪੁਸ਼ਟੀ ਨੂੰ ਲਾਗੂ ਨਹੀਂ ਕੀਤਾ ਗਿਆ ਹੈ।

## ਡਾਟਾ ਅਧਿਕਾਰ ਅਤੇ ਗੋਪਨੀਯਤਾ

MIT ਸਾਫਟਵੇਅਰ ਲਾਇਸੈਂਸ ਆਯਾਤ ਕੀਤੇ ਕਾਰੋਬਾਰੀ ਰਿਕਾਰਡਾਂ ਉੱਤੇ ਅਧਿਕਾਰ ਨਹੀਂ ਦਿੰਦਾ। ਸਿਰਫ਼ ਸਰੋਤ ਦਾ ਜ਼ਿਕਰ ਕਰਨ ਨਾਲ Google Maps, 2GIS, Yandex Maps ਜਾਂ ਹੋਰ ਸਰੋਤਾਂ ਤੋਂ ਡਾਟਾ ਕਾਪੀ ਕਰਨ ਦੀ ਇਜਾਜ਼ਤ ਨਹੀਂ ਮਿਲਦੀ। ਡਾਟਾਸੈੱਟ ਵਰਤਣ ਤੋਂ ਪਹਿਲਾਂ ਸਟੋਰੇਜ, ਪ੍ਰਕਾਸ਼ਨ ਅਤੇ ਮੁੜ ਵੰਡ ਦੀਆਂ ਇਜਾਜ਼ਤਾਂ ਜਾਂਚੋ। [ਡਾਟਾ ਦੀ ਉਤਪੱਤੀ ਅਤੇ ਸਮੀਖਿਆ ਦੀਆਂ ਸੀਮਾਵਾਂ](../../docs/DATA_PROVENANCE.md) ਵੇਖੋ।

ਖੁਦ ਪ੍ਰਕਾਸ਼ਿਤ ਕੀਤੀ ਸੰਪਰਕ ਜਾਣਕਾਰੀ ਜਨਤਕ ਹੁੰਦੀ ਹੈ; ਪ੍ਰਬੰਧਨ ਕੁੰਜੀਆਂ ਨਿੱਜੀ ਹੁੰਦੀਆਂ ਹਨ। ਡਾਟਾਬੇਸ ਅਤੇ ਬੈਕਅੱਪ ਨੂੰ ਜਨਤਕ ਤੌਰ 'ਤੇ ਉਪਲਬਧ ਡਾਇਰੈਕਟਰੀਆਂ ਤੋਂ ਬਾਹਰ ਰੱਖੋ, ਅਤੇ ਸੁਧਾਰਾਂ ਅਤੇ ਹਟਾਉਣ ਦੀਆਂ ਬੇਨਤੀਆਂ ਲਈ ਇੱਕ ਸੰਪਰਕ ਪ੍ਰਦਾਨ ਕਰੋ। ਡਿਪਲੋਇਮੈਂਟ ਤੋਂ ਪਹਿਲਾਂ [ਗੋਪਨੀਯਤਾ](../../PRIVACY.md) ਅਤੇ [ਸੁਰੱਖਿਆ](../../SECURITY.md) ਬਾਰੇ ਪੜ੍ਹੋ।

## ਵਿਕਾਸ ਅਤੇ ਅਨੁਵਾਦ

```sh
npm run dev
npm run check
npx playwright install chromium
npm run test:e2e
npm run format:check
```

GitHub ਐਕਸ਼ਨ ਕਿਸਮਾਂ, API ਅਤੇ ਬ੍ਰਾਊਜ਼ਰ ਵਰਕਫਲੋ ਦੀ ਜਾਂਚ ਕਰਦਾ ਹੈ, ਅਤੇ ਡਿਫੌਲਟ ਅਤੇ ਅਸਲ CAD ਕੰਟੇਨਰ। ਟੈਸਟਾਂ ਵਿੱਚ ਕਾਲਪਨਿਕ ਰਿਕਾਰਡਾਂ ਦੀ ਵਰਤੋਂ ਕੀਤੀ ਜਾਂਦੀ ਹੈ। ਸਹੀ ਸਬੂਤ, ਕਵਰੇਜ ਅਤੇ ਬਾਕੀ ਰਹਿੰਦੀਆਂ ਸੀਮਾਵਾਂ [ਵੈਲੀਡੇਸ਼ਨ](../../docs/VALIDATION.md) ਅਤੇ [ਉਤਪਾਦ ਦਾ ਦਾਇਰਾ](../../docs/PRODUCT.md) ਵਿੱਚ ਦਰਜ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।

ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਦਿੱਤੀ ਗਈ README ਫਾਈਲ, ਪੂਰੀ ਤਰ੍ਹਾਂ ਅਨੁਵਾਦ ਕੀਤੇ ਗਏ ਸੰਸਕਰਣਾਂ ਲਈ ਇੱਕ ਹਵਾਲਾ ਵਜੋਂ ਵਰਤੀ ਜਾਂਦੀ ਹੈ। [ਭਾਸ਼ਾ ਸੂਚਕ](../../docs/i18n/README.md) ਅਨੁਵਾਦ ਦੇ ਸੰਭਾਲ ਅਤੇ ਸਮੀਖਿਆ ਦੀਆਂ ਸੀਮਾਵਾਂ ਬਾਰੇ ਦੱਸਦੀ ਹੈ। ਇੰਟਰਫੇਸ ਦਾ ਸਥਾਨਕੀਕਰਨ ਉਪਭੋਗਤਾ ਦੁਆਰਾ ਬਣਾਈਆਂ ਗਈਆਂ ਸੂਚੀਆਂ, ਪ੍ਰੋਜੈਕਟ ਦੀ ਸਮੱਗਰੀ ਜਾਂ ਹਰੇਕ ਬਾਹਰੀ ਤਕਨੀਕੀ ਜਾਂਚ ਦਾ ਅਨੁਵਾਦ ਨਹੀਂ ਕਰਦਾ।

## ਲਾਇਸੈਂਸ ਅਤੇ ਯੋਗਦਾਨ

ਮੂਲ ਕੋਡ, UI, SVG ਚਿੱਤਰ, ਦਸਤਾਵੇਜ਼ ਅਤੇ ਪੈਰਾਮੀਟ੍ਰਿਕ ਜਨਰੇਟਰ [MIT ਲਾਇਸੈਂਸ](../../LICENSE) ਦੇ ਅਧੀਨ ਹਨ। ਨਿਰਭਰਤਾਵਾਂ ਆਪਣੇ ਲਾਇਸੈਂਸ ਅਤੇ ਨੋਟਿਸ ਰੱਖਦੀਆਂ ਹਨ। ਉਪਭੋਗਤਾ ਮਾਡਲਾਂ ਦਾ ਵੱਖਰਾ ਲਾਇਸੈਂਸ ਹੁੰਦਾ ਹੈ, ਜੋ ਉਨ੍ਹਾਂ ਦੇ ਲੇਖਕਾਂ ਦੁਆਰਾ ਚੁਣਿਆ ਜਾਂਦਾ ਹੈ। ਕਾਲਪਨਿਕ ਡੈਮੋ ਪ੍ਰੋਫਾਈਲਾਂ ਅਤੇ ਡੈਮੋ ਤਕਨੀਕੀ ਲੋੜਾਂ ਦੇ ਟੈਕਸਟ, ਅਤੇ ਤਿੰਨ ਤਿਆਰ ਕੀਤੇ ਡੈਮੋ ਡਿਜ਼ਾਈਨ CC0 ਦੇ ਅਧੀਨ ਸਮਰਪਿਤ ਹਨ; ਜਨਰੇਟਰ MIT ਦੇ ਅਧੀਨ ਰਹਿੰਦਾ ਹੈ। [ਤੀਜੀ ਧਿਰ ਦੇ ਨੋਟਿਸ](../../THIRD_PARTY_NOTICES.md) ਦੇਖੋ।

ਇਹ ਸੁਤੰਤਰ ਲਾਗੂਕਰਨ [3d-online.app](https://3d-online.app) ਦੇ ਵਿਚਾਰ ਨੂੰ ਵਿਕਸਤ ਕਰਦਾ ਹੈ। ਅਸਲ ਉਤਪਾਦਨ ਖਾਤੇ, ਗੁਪਤ ਜਾਣਕਾਰੀ, ਨਿੱਜੀ Git ਇਤਿਹਾਸ ਅਤੇ ਉਪਭੋਗਤਾ ਫਾਈਲਾਂ ਸ਼ਾਮਲ ਨਹੀਂ ਹਨ। ਅਨੁਕੂਲਿਤ MIT Neofab CAD ਕੰਪਾਈਲਰ ਆਪਣਾ [ਅਸਲ ਲਾਇਸੈਂਸ ਅਤੇ ਸਰੋਤ ਨੋਟਿਸ](../../cad-worker/NOTICE.md) ਬਰਕਰਾਰ ਰੱਖਦਾ ਹੈ।

ਯੋਗਦਾਨ ਵਿੱਚ ਕੋਡ, ਅਨੁਵਾਦ ਵਿੱਚ ਸੁਧਾਰ, ਵਰਤੋਂ ਵਿੱਚ ਸੁਧਾਈ, ਖੁੱਲੇ ਪੈਰਾਮੀਟ੍ਰਿਕ ਹਿੱਸੇ, ਇੰਸਟਾਲੇਸ਼ਨ ਦੀ ਜਾਂਚ ਅਤੇ ਅਸਲ ਵਰਕਸ਼ਾਪਾਂ ਤੋਂ ਪ੍ਰਾਪਤ ਫੀਡਬੈਕ ਸ਼ਾਮਲ ਹੋ ਸਕਦੇ ਹਨ। [CONTRIBUTING.md](../../CONTRIBUTING.md) ਤੋਂ ਸ਼ੁਰੂ ਕਰੋ।
