نقشے پر کوئی پروڈکشن اسٹوڈیو تلاش کریں، ان کی صلاحیتوں کی جانچ کریں اور براہ راست ان سے رابطہ کریں۔ اگر آپ کا ورکشاپ درج نہیں ہے، تو اس کے رابطے اور خدمات شامل کریں: یہ معلومات فوری طور پر ظاہر ہو جائیں گی۔ بعد میں اپنی معلومات میں ترمیم یا حذف کرنے کے لیے نجی مینجمنٹ لنک محفوظ کریں۔ ڈیفالٹ کیٹلاگ میں کوئی اکاؤنٹ، ای میل کی تصدیق یا منظوری کا عمل نہیں ہے۔

OpenPrint کو Node.js 24 اور مقامی SQLite کے ساتھ چلائیں۔ Vercel، Supabase، ایک ای میل فراہم کنندہ، ادائیگی شدہ اے آئی اور تیسرے فریق کے ذریعے لاگ ان کرنے کی ضرورت نہیں ہے۔ GitHub سورس اور ریلیز کو ہوسٹ کرتا ہے۔ ایک مشترکہ ویب سائٹ جس میں مواد جمع کرایا جا سکتا ہے، اس کے لیے ایک فعال API سرور کی ضرورت ہوتی ہے۔ [GitHub صفحات](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) بذاتِ خود Node.js API کو نہیں چلا سکتے اور نہ ہی زائرین کے تبادلوں کو برقرار رکھ سکتے ہیں۔

## کیٹلاگ کی خصوصیات

- نام، شہر اور ٹیکنالوجی کے ذریعے تلاش کریں۔ نقشے میں فہرست کے صفحات سے قطع نظر، متعلقہ مقامات شامل ہیں۔
- اکاؤنٹ کے بغیر شائع کریں۔ نقشے پر ایک نقطہ منتخب کریں یا کوآرڈینیٹس درج کریں؛ کوآرڈینیٹس کے بغیر درج کردہ معلومات تلاش کے لیے دستیاب رہیں گی۔
- کسی ایک اشتہار کو ترمیم کریں یا حذف کریں، اس کے نجی لنک کے ساتھ۔ ورژن کی جانچ مختلف ٹیبز میں متضاد ترمیمات سے بچاؤ کرتی ہے۔
- پبلش کرنے سے پہلے موجودہ اسٹوڈیوز تلاش کریں۔ بالکل ایک جیسے نام، شہر اور پتہ والے اندراجات خود بخود مسترد کر دیے جائیں گے۔
- ماخذ کی نشاندہی کے ساتھ ایک کیٹلاگ درآمد کریں۔ آپریٹر کے ذریعے کی جانے والی درآمدات، خود شائع کردہ فہرستوں کو تبدیل نہیں کر سکتی۔
- کسی API کی کی ضرورت کے بغیر OpenStreetMap ٹائلز دیکھیں۔ جب کوئی نقشہ دکھایا جاتا ہے، تو ٹائلز لوڈ ہوتی ہیں، بشمول ڈیفالٹ لینڈنگ پیج۔
- زبان کے مینو سے انٹرفیس کی زبان منتخب کریں۔ اوپر دیے گئے زبان کے انڈیکس کے ذریعے اپنی زبان میں مکمل ریڈمی (README) پڑھیں۔

یہ پلیٹ فارم کسی بھی کاروبار کی ملکیت یا خدمات کی معیار کی تصدیق نہیں کرتا۔ براہ کرم اسٹوڈیو سے آلات، صلاحیتوں اور شرائط کی تصدیق کریں۔ جس کے پاس نجی مینجمنٹ کا لنک ہوگا، وہ اس اشتہار کو کنٹرول کر سکتا ہے۔ اسے نجی رکھیں؛ یہاں کوئی ای میل ریکوری نہیں ہے۔ [خود اشاعت گائیڈ](../../docs/OPEN_CATALOG.md) پڑھیں۔

## اپنا الگ انسٹینس چلائیں

Node.js ورژن 24 انسٹال کریں، اس ریپوزٹری کو کلون کریں اور یہ کمانڈ چلائیں:

```sh
npm ci
npm run build
cp .env.example .env
npm start
```

اوپن `http://localhost:3000`۔ ڈیفالٹ `APP_MODE=catalog` کے لیے کسی منتظم یا صارف کی ترتیب کی ضرورت نہیں ہے۔ [خود-میزبانی گائیڈ](../../docs/SELF_HOSTING.md) کا استعمال کرتے ہوئے `APP_URL`، HTTPS اور بیک اپ کو ترتیب دیں۔ Docker کمپوز بھی دستیاب ہے: `docker compose up --build -d`۔

اس میں ایک ایپلیکیشن پروسیس SQLite کے ساتھ ایک مقامی ڈسک پر انسٹالیشن کی حمایت کی جاتی ہے۔ خودکار اشاعت اور درخواست کی حدیں، نگرانی کے نظام کے بغیر، بد استعمال کو محدود کرتی ہیں۔ ایک مشترکہ دفتر کا آئی پی ایڈریس، اشاعت کی حد کو شیئر کر سکتا ہے۔ عوامی انسٹنس کھولنے سے پہلے [حدود اور مینجمنٹ لنک کی فعالیت](../../docs/OPEN_CATALOG.md) دیکھیں۔

کسی موجودہ ڈیٹا سیٹ کے حقوق کی جانچ کرنے کے بعد، [کیٹلاگ امپورٹ سی ایل آئی](../../docs/CATALOG_IMPORT.md) استعمال کریں۔ انسٹینس ڈیٹا سیٹس، اپ لوڈ اور بیک اپ کو ریپوزٹری یا کنٹینر امیجز میں شامل نہیں کیا جاتا ہے۔

## اختیاری کمیونٹی اور Neofab موڈ

نجی پروجیکٹس، سروس فراہم کرنے والوں کے کوٹس، ماڈل لائبریری اور Neofab اسٹوڈیو کو فعال کرنے کے لیے `APP_MODE=community` کو واضح طور پر سیٹ کریں۔ ان ورک فلو میں ان کے اپنے اکاؤنٹس اور اجازت نامے استعمال ہوتے ہیں۔ موڈ تبدیل کرنے سے محفوظ کردہ ڈیٹا برقرار رہتا ہے۔ کیٹلاگ موڈ اس کے API کے ذریعے نجی کمیونٹی کی تاریخ کو ظاہر نہیں کرتا اور نہ ہی زیرِ التوا CAD کام کو دوبارہ شروع کرتا ہے۔

[Neofab اسٹوڈیو](../../docs/NEOFAB_SETUP.md) ورژن پر مبنی مینوفیکچرنگ بریف، مواد کی فہرست اور محدود اعلامی CAD کو STEP/STL کے ذریعے ایکسپورٹ کرنے کی سہولت فراہم کرتا ہے۔ CAD اور اے آئی (مصنوعی ذہانت) اختیاری ہیں۔ اے آئی کے ذریعے پیش کردہ تجاویز پر جائزہ لینے اور ایک علیحدہ درخواست کے مرحلے کی ضرورت ہوتی ہے۔ یہ خود بخود آرڈرز شائع نہیں کرتے یا جیومیٹری نہیں بناتے ہیں۔ CAM، جی-کوڈ اور مادی مینوفیکچرنگ کی تصدیق ابھی تک نافذ نہیں کی گئی ہے۔

## ڈیٹا کے حقوق اور رازداری

MIT سافٹ ویئر لائسنس درآمد شدہ کاروباری ریکارڈوں کے استعمال کے حقوق نہیں دیتا۔ محض حوالہ دینے سے Google میپس، 2GIS، یانڈیکس میپس یا دیگر ذرائع سے ڈیٹا کی نقل کرنے کی اجازت نہیں ملتی۔ کسی ڈیٹا سیٹ کو استعمال کرنے سے پہلے، اس کے ذخیرہ کرنے، شائع کرنے اور دوبارہ تقسیم کرنے کے حقوق کی تصدیق کریں۔ [ڈیٹا کی اصل اور جائزہ کی حدود](../../docs/DATA_PROVENANCE.md) دیکھیں۔

خود شائع کردہ رابطہ کی معلومات عام ہیں؛ انتظامی کلیدیں نجی ہیں۔ ڈیٹا بیس اور بیک اپ کو عام طور پر دستیاب ڈائریکٹریوں سے الگ رکھیں، اور اصلاحات اور حذف کرنے کی درخواستوں کے لیے ایک رابطہ فراہم کریں۔ استعمال کرنے سے پہلے [رازداری](../../PRIVACY.md) اور [حفاظت](../../SECURITY.md) کے بارے میں معلومات پڑھیں۔

## ترقی اور ترجمہ

```sh
npm run dev
npm run check
npx playwright install chromium
npm run test:e2e
npm run format:check
```

GitHub ایکشنز، اقسام، API اور براؤزر ورک فلو کی جانچ کرتا ہے، اور ڈیفالٹ اور مقامی CAD کنٹینرز کا استعمال کرتا ہے۔ ٹیسٹ میں فرضی ریکارڈ استعمال ہوتے ہیں۔ درست ثبوت، کوریج اور باقی ماندہ حدود کو [ویلڈیشن](../../docs/VALIDATION.md) اور [پروڈکٹ اسکوپ](../../docs/PRODUCT.md) میں درج کیا جاتا ہے۔

انگریزی میں موجود ریڈمی فائل مکمل ترجمہ شدہ ایڈیشنز کے لیے ایک مرجع دستاویز ہے۔ [زبان کا انڈیکس](../../docs/i18n/README.md) ترجمے کی دیکھ بھال اور جائزہ لینے کی حدوں کے بارے میں معلومات فراہم کرتا ہے۔ انٹرفیس کی مقامی زبان میں تبدیلی میں صارف کے لکھے ہوئے مواد، پروجیکٹ کے مواد یا ہر بیرونی تکنیکی تشخیصی معلومات کا ترجمہ شامل نہیں ہے۔
