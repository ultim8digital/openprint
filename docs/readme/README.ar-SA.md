ابحث عن ورشة عمل على الخريطة، وتحقق من إمكانياتها، وتواصل معها مباشرةً. إذا لم تظهر ورشة عملك، أضف معلومات الاتصال والخدمات التي تقدمها: ستظهر معلوماتك على الفور. احفظ رابط الإدارة الخاص بك لتتمكن من تعديل أو حذف معلومات ورشة عملك لاحقًا. لا يحتوي الكتالوج الافتراضي على أي حسابات أو تأكيد عبر البريد الإلكتروني أو قائمة انتظار للموافقة.

شغّل OpenPrint باستخدام Node.js 24 و SQLite محليًا. لا يلزم وجود Vercel أو Supabase (مزوّد خدمة بريد إلكتروني) أو خدمة ذكاء اصطناعي مدفوعة أو تسجيل دخول عبر جهات خارجية. تستضيف GitHub الكود المصدري والإصدارات؛ ويتطلب موقع ويب مشترك يقبل المشاركات وجود خادم API قيد التشغيل. لا يمكن لـ [GitHub صفحات](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) وحدها تشغيل Node.js API أو حفظ تغييرات الزوار.

## ميزات الكتالوج

- ابحث بالاسم أو المدينة أو نوع التكنولوجيا. تعرض الخريطة المواقع المطابقة بغض النظر عن طريقة عرض القائمة.
- انشر دون الحاجة إلى حساب. اختر نقطة على الخريطة أو أدخل الإحداثيات؛ تظل القوائم التي لا تحتوي على إحداثيات قابلة للبحث.
- حرّر أو احذف إدخالًا واحدًا مع رابطه الخاص. تضمن عمليات التحقق من الإصدار الحماية من التعديلات المتضاربة في علامات التبويب المختلفة.
- ابحث عن الاستوديوهات الموجودة قبل النشر. يتم رفض التكرارات الدقيقة للاسم والمدينة والعنوان تلقائيًا.
- استورد كتالوجًا مع الإشارة إلى مصدره. لا يمكن لعمليات الاستيراد التي يقوم بها المشغل أن تحل محل القوائم المنشورة ذاتيًا.
- عرض OpenStreetMap من الخرائط بدون API. يتم تحميل الخرائط عند عرض الخريطة، بما في ذلك صفحة البداية الافتراضية.
- اختر لغة الواجهة من قائمة اللغات. اقرأ ملف "اقرأني" الكامل بلغتك من خلال فهرس اللغات أعلاه.

لا تتحقق عملية النشر من ملكية المنشأة أو جودة الخدمة. يرجى التأكد من المعدات والإمكانيات والشروط مع الاستوديو. يمكن لأي شخص يمتلك رابط الإدارة الخاص التحكم في هذا الإدراج. حافظ على سرية الرابط؛ لا يمكن استعادة الوصول عبر البريد الإلكتروني. اقرأ [دليل النشر الذاتي](../../docs/OPEN_CATALOG.md).

## شغّل نسختك الخاصة

قم بتثبيت Node.js 24، واستنسخ هذا المستودع، ثم قم بتشغيل:

```sh
npm ci
npm run build
cp .env.example .env
npm start
```

Open `http://localhost:3000`. لا يتطلب الإعداد الافتراضي `APP_MODE=catalog` أي إعدادات خاصة للمسؤول أو المستخدم. قم بتكوين `APP_URL` وHTTPS وعمليات النسخ الاحتياطي باستخدام [دليل الاستضافة الذاتية](../../docs/SELF_HOSTING.md). Docker تتوفر أيضًا أداة Compose: `docker compose up --build -d`.

طريقة النشر المدعومة هي عملية تطبيق واحدة مع SQLite على قرص محلي. تحدّ آلية النشر التلقائي وحصص الطلبات من إساءة الاستخدام دون الحاجة إلى قائمة انتظار للإشراف. يمكن لعنوان IP مشترك أن يشارك في حصة النشر. راجع [الحدود وسلوك إدارة الروابط](../../docs/OPEN_CATALOG.md) قبل فتح نسخة عامة.

استخدم واجهة سطر الأوامر [لاستيراد الكتالوج](../../docs/CATALOG_IMPORT.md) لمجموعة بيانات موجودة بعد التحقق من حقوقها. لا يتم تجميع مجموعات البيانات الخاصة بالمثيل، والملفات التي تم تحميلها، والنسخ الاحتياطية في المستودع أو صور الحاويات.

## وضع مجتمعي اختياري ووضع Neofab

عيّن `APP_MODE=community` بشكل صريح لتفعيل المشاريع الخاصة، وعروض الأسعار من مزودي الخدمة، ومكتبة النماذج، وNeofab Studio. تستخدم هذه العمليات حساباتها وأذوناتها الخاصة. يؤدي تبديل الأوضاع إلى الحفاظ على البيانات المخزنة. لا يعرض وضع "الكتالوج" سجل المجتمع الخاص من خلال API أو يستأنف المهام المعلقة CAD.

يدعم [Neofab Studio](../../docs/NEOFAB_SETUP.md) مستندات التصنيع ذات الإصدارات، وقوائم المواد، وCAD التعريفية المحددة مع تصدير STEP/STL. CAD والذكاء الاصطناعي اختياريان. تتطلب مقترحات الذكاء الاصطناعي مراجعة وخطوة تطبيق منفصلة؛ فهي لا تنشر الطلبات أو تبني الهندسة تلقائيًا. لم يتم تطبيق CAM ورمز G والتحقق الفعلي من التصنيع.

## حقوق البيانات والخصوصية

لا يمنح ترخيص برنامج MIT الحقوق اللازمة للبيانات التجارية المستوردة. مجرد الإشارة إلى المصدر لا يسمح بنسخ البيانات من Google Maps أو 2GIS أو Yandex Maps أو مصادر أخرى. تحقق من الأذونات الخاصة بالتخزين والنشر وإعادة التوزيع قبل استخدام مجموعة بيانات. راجع [حدود مصدر البيانات ومراجعتها](../../docs/DATA_PROVENANCE.md).

معلومات الاتصال التي يتم نشرها ذاتيًا متاحة للعامة؛ مفاتيح الإدارة خاصة. احتفظ بقواعد البيانات والنسخ الاحتياطية خارج الدلائل المتاحة للعامة، وقدم جهة اتصال لتلقي طلبات التصحيح والحذف. اقرأ [سياسة الخصوصية](../../PRIVACY.md) و[سياسة الأمان](../../SECURITY.md) قبل النشر.

## التطوير والترجمة

```sh
npm run dev
npm run check
npx playwright install chromium
npm run test:e2e
npm run format:check
```

GitHub تتحقق الإجراءات من أنواع البيانات، وAPI وسير العمل في المتصفح، والحاويات الافتراضية والأصلية CAD. تستخدم الاختبارات سجلات وهمية. يتم تسجيل الأدلة الدقيقة، ومستوى التغطية، والحدود المتبقية في [التحقق من الصحة](../../docs/VALIDATION.md) و[نطاق المنتج](../../docs/PRODUCT.md).

يُعد ملف README باللغة الإنجليزية هو المرجع للإصدارات المترجمة الكاملة. توثق [قائمة اللغات](../../docs/i18n/README.md) حدود صيانة الترجمة ومراجعتها. لا تتضمن عملية توطين الواجهة ترجمة القوائم التي يضيفها المستخدمون، أو محتوى المشروع، أو كل التقارير الفنية الخارجية.
