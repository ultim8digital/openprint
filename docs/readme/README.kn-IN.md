# OpenPrint

**ಮುದ್ರಣ ಸ್ಟುಡಿಯೋಗಳು ಮತ್ತು ಕಾರ್ಯಾಗಾರಗಳ ಮುಕ್ತ ಡೈರೆಕ್ಟರಿ. ನೋಂದಣಿ ಅಥವಾ ಮಾಡರೇಟರ್‌ಗಳಿಲ್ಲ.**

[Languages / Языки](../../docs/i18n/README.md) · [English](../../README.md) · [Русский](../../docs/readme/README.ru.md)

ನಕ್ಷೆಯಲ್ಲಿ ತಯಾರಕನನ್ನು ಹುಡುಕಿ, ಅವರ ಸಾಮರ್ಥ್ಯಗಳನ್ನು ಪರಿಶೀಲಿಸಿ ಮತ್ತು ನೇರವಾಗಿ ಅವರನ್ನು ಸಂಪರ್ಕಿಸಿ. ನಿಮ್ಮ ಕಾರ್ಯಾಗಾರವು ಇಲ್ಲದಿದ್ದರೆ, ಅದರ ಸಂಪರ್ಕ ಮಾಹಿತಿ ಮತ್ತು ಸೇವೆಗಳನ್ನು ಸೇರಿಸಿ: ಅದು ತಕ್ಷಣವೇ ಪಟ್ಟಿಯಲ್ಲಿ ಕಾಣಿಸುತ್ತದೆ. ನಂತರ ಸಂಪಾದಿಸಲು ಅಥವಾ ನಿಮ್ಮ ಪಟ್ಟಿಯನ್ನು ತೆಗೆದುಹಾಕಲು, ಖಾಸಗಿ ನಿರ್ವಹಣಾ ಲಿಂಕ್ ಅನ್ನು ಉಳಿಸಿ. ಪೂರ್ವನಿಯಮಿತ ಕ್ಯಾಟಲಾಗ್‌ನಲ್ಲಿ ಯಾವುದೇ ಖಾತೆಗಳು, ಇಮೇಲ್ ದೃಢೀಕರಣ ಅಥವಾ ಅನುಮೋದನಾ ಕ್ಯೂ ಇರುವುದಿಲ್ಲ.

OpenPrint ಅನ್ನು Node.js 24 ಮತ್ತು ಸ್ಥಳೀಯ SQLite ಜೊತೆಗೆ ಚಲಾಯಿಸಿ. Vercel, Supabase, ಇಮೇಲ್ ಸೇವೆ ಒದಗಿಸುವವರು, ಪಾವತಿಸಿದ AI ಮತ್ತು ಮೂರನೇ ವ್ಯಕ್ತಿಯ ಲಾಗಿನ್ ಅಗತ್ಯವಿಲ್ಲ. GitHub ಮೂಲವನ್ನು ಮತ್ತು ಬಿಡುಗಡೆಗಳನ್ನು ಹೋಸ್ಟ್ ಮಾಡುತ್ತದೆ; ಸಲ್ಲಿಸುವಿಕೆಗಳನ್ನು ಸ್ವೀಕರಿಸುವ ಒಂದು ಸಾಮಾನ್ಯ ವೆಬ್‌ಸೈಟ್‌ಗೆ ಚಾಲನೆಯಲ್ಲಿರುವ API ಸರ್ವರ್ ಅಗತ್ಯವಿದೆ. [GitHub ಪುಟಗಳು](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) ಮಾತ್ರ Node.js API ಅನ್ನು ಚಲಾಯಿಸಲು ಅಥವಾ ಸಂದರ್ಶಕರ ಬದಲಾವಣೆಗಳನ್ನು ಉಳಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ.

## ವಿವರಣೆಯ ವೈಶಿಷ್ಟ್ಯಗಳು

- ಹೆಸರು, ನಗರ ಮತ್ತು ತಂತ್ರಜ್ಞಾನದ ಪ್ರಕಾರ ಹುಡುಕಿ. ನಕ್ಷೆಯಲ್ಲಿ ಪಟ್ಟಿ ಪುಟಗಳ ಸಂಖ್ಯೆಗಿಣಿಸದೆ, ಹೊಂದಾಣಿಕೆಯ ಸ್ಥಳಗಳು ಪ್ರದರ್ಶಿತವಾಗುತ್ತವೆ.
- ಖಾತೆಯಿಲ್ಲದೆ ಪ್ರಕಟಿಸಿ. ನಕ್ಷೆಯಲ್ಲಿನ ಒಂದು ನಿರ್ದಿಷ್ಟ ಸ್ಥಳವನ್ನು ಆಯ್ಕೆ ಮಾಡಿ ಅಥವಾ ನಿರ್ದೇಶಾಂಕಗಳನ್ನು ನಮೂದಿಸಿ; ನಿರ್ದೇಶಾಂಕಗಳಿಲ್ಲದ ಪಟ್ಟಿಗಳು ಹುಡುಕಲು ಲಭ್ಯವಿರುತ್ತವೆ.
- ಒಂದು ಪಟ್ಟಿಯನ್ನು ಅದರ ಖಾಸಗಿ ಲಿಂಕ್‌ನೊಂದಿಗೆ ಸಂಪಾದಿಸಿ ಅಥವಾ ಅಳಿಸಿ. ಆವೃತ್ತಿ ಪರಿಶೀಲನೆಗಳು ವಿಭಿನ್ನ ಟ್ಯಾಬ್‌ಗಳಲ್ಲಿನ ವಿರೋಧಾತ್ಮಕ ಬದಲಾವಣೆಗಳಿಂದ ರಕ್ಷಿಸುತ್ತವೆ.
- ಪ್ರಕಟಿಸುವ ಮೊದಲು, ಈಗಾಗಲೇ ಇರುವ ಸ್ಟುಡಿಯೋಗಳನ್ನು ಹುಡುಕಿ. ಒಂದೇ ಹೆಸರಿನ, ಒಂದೇ ನಗರದ ಮತ್ತು ಒಂದೇ ವಿಳಾಸದ ಸ್ಟುಡಿಯೋಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ತಿರಸ್ಕರಿಸಲಾಗುತ್ತದೆ.
- ಮೂಲವನ್ನು ಉಲ್ಲೇಖಿಸಿರುವ ಕ್ಯಾಟಲಾಗ್ ಅನ್ನು ಆಮದು ಮಾಡಿ. ನಿರ್ವಾಹಕರು ಆಮದು ಮಾಡಿದವು ಸ್ವತಃ ಪ್ರಕಟಿಸಿದ ಪಟ್ಟಿಗಳನ್ನು ಬದಲಾಯಿಸಲಾರರು.
- ಒಂದು API ಕೀ ಇಲ್ಲದೆ OpenStreetMap ಟೈಲ್‌ಗಳನ್ನು ವೀಕ್ಷಿಸಿ. ನಕ್ಷೆಯನ್ನು ಪ್ರದರ್ಶಿಸಿದಾಗ ಟೈಲ್‌ಗಳು ಲೋಡ್ ಆಗುತ್ತವೆ, ಇದರಲ್ಲಿ ಡೀಫಾಲ್ಟ್ ಲ್ಯಾಂಡಿಂಗ್ ಪುಟವೂ ಸೇರಿರುತ್ತದೆ.
- ಭಾಷಾ ಮೆನುದಿಂದ ಇಂಟರ್‌ಫೇಸ್ ಭಾಷೆಯನ್ನು ಆಯ್ಕೆ ಮಾಡಿ. ಮೇಲಿನ ಭಾಷಾ ಸೂಚಿಕೆ ಮೂಲಕ ನಿಮ್ಮ ಭಾಷೆಯಲ್ಲಿ ಸಂಪೂರ್ಣವಾದ README ಅನ್ನು ಓದಿ.

ಪ್ರಕಟಣೆಯು ವ್ಯಾಪಾರದ ಮಾಲೀಕತ್ವ ಅಥವಾ ಸೇವಾ ಗುಣಮಟ್ಟವನ್ನು ಪರಿಶೀಲಿಸುವುದಿಲ್ಲ. ಉಪಕರಣಗಳು, ಸಾಮರ್ಥ್ಯಗಳು ಮತ್ತು ನಿಯಮಗಳನ್ನು ಸ್ಟುಡಿಯೊದೊಂದಿಗೆ ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ. ಖಾಸಗಿ ನಿರ್ವಹಣಾ ಲಿಂಕ್ ಹೊಂದಿರುವ ಯಾರಾದರೂ ಆ ಪಟ್ಟಿಯನ್ನು ನಿಯಂತ್ರಿಸಬಹುದು. ಅದನ್ನು ಖಾಸಗಿಯಾಗಿರಿಸಿ; ಇಮೇಲ್ ಅನ್ನು ಮರುಸ್ಥಾಪಿಸುವ ಅವಕಾಶವಿಲ್ಲ. [ಸ್ವಯಂ-ಪ್ರಕಟಣಾ ಮಾರ್ಗದರ್ಶಿ](../../docs/OPEN_CATALOG.md) ಅನ್ನು ಓದಿ.

## ನಿಮ್ಮ ಸ್ವಂತ ಪ್ರತಿಯನ್ನು ಚಲಾಯಿಸಿ

Node.js 24 ಅನ್ನು ಸ್ಥಾಪಿಸಿ, ಈ ರೆಪೊಸಿಟರಿಯನ್ನು ಕ್ಲೋನ್ ಮಾಡಿ ಮತ್ತು ಚಲಾಯಿಸಿ:

```sh
npm ci
npm run build
cp .env.example .env
npm start
```

`http://localhost:3000` ತೆರೆಯಿರಿ. ಪೂರ್ವನಿಯೋಜಿತ `APP_MODE=catalog`ಗೆ ನಿರ್ವಾಹಕ ಅಥವಾ ಬಳಕೆದಾರರನ್ನು ಹೊಂದಿಸುವ ಅಗತ್ಯವಿಲ್ಲ. [ಸ್ವಯಂ ಹೋಸ್ಟಿಂಗ್ ಮಾರ್ಗದರ್ಶಿ](../../docs/SELF_HOSTING.md) ಬಳಸಿ `APP_URL`, HTTPS ಮತ್ತು ಬ್ಯಾಕಪ್‌ಗಳನ್ನು ಹೊಂದಿಸಿ. Docker Compose ಕೂಡ ಲಭ್ಯವಿದೆ: `docker compose up --build -d`.

ಅನುಮತಿಸಲಾದ ನಿಯೋಜನೆಯು ಒಂದು ಅಪ್ಲಿಕೇಶನ್ ಪ್ರಕ್ರಿಯೆಯಾಗಿದ್ದು, ಅದು ಸ್ಥಳೀಯ ಡಿಸ್ಕ್‌ನಲ್ಲಿ SQLite ಅನ್ನು ಹೊಂದಿರುತ್ತದೆ. ಸ್ವಯಂಚಾಲಿತ ಪ್ರಕಟಣೆ ಮತ್ತು ವಿನಂತಿ ಕೋಟಾಗಳು, ಮೇಲ್ವಿಚಾರಣಾ ಕ್ಯೂ ಇಲ್ಲದೆ ದುರುಪಯೋಗವನ್ನು ತಡೆಯುತ್ತದೆ. ಒಂದು ಹಂಚಿಕೆಯ ಕಚೇರಿ IP, ಪ್ರಕಟಣೆ ಕೋಟಾವನ್ನು ಹಂಚಿಕೊಳ್ಳಬಹುದು. ಸಾರ್ವಜನಿಕ ಇನ್‌ಸ್ಟೆನ್ಸ್ ಅನ್ನು ತೆರೆಯುವ ಮೊದಲು [ಮಿತಿಗಳು ಮತ್ತು ನಿರ್ವಹಣಾ-ಲಿಂಕ್‌ನ ವರ್ತನೆ](../../docs/OPEN_CATALOG.md) ಅನ್ನು ನೋಡಿ.

ಅದರ ಹಕ್ಕುಗಳನ್ನು ಪರಿಶೀಲಿಸಿದ ನಂತರ, ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಡೇಟಾ ಸೆಟ್‌ಗಾಗಿ [ಕ್ಯಾಟಲಾಗ್ ಆಮದು CLI](../../docs/CATALOG_IMPORT.md) ಅನ್ನು ಬಳಸಿ. ಇನ್‌ಸ್ಟೆನ್ಸ್ ಡೇಟಾ ಸೆಟ್‌ಗಳು, ಅಪ್‌ಲೋಡ್‌ಗಳು ಮತ್ತು ಬ್ಯಾಕಪ್‌ಗಳನ್ನು ರೆಪೊಸಿಟರಿ ಅಥವಾ ಕಂಟೈನರ್ ಚಿತ್ರಗಳಲ್ಲಿ ಸೇರಿಸಲಾಗಿರುವುದಿಲ್ಲ.

## ಐಚ್ಛಿಕ ಸಮುದಾಯ ಮತ್ತು Neofab ಮೋಡ್

ಖಾಸಗಿ ಯೋಜನೆಗಳು, ಸೇವಾ ಪ್ರದಾತರ ಉದ್ಧರಣಗಳು, ಮಾದರಿ ಗ್ರಂಥಾಲಯ ಮತ್ತು Neofab ಸ್ಟುಡಿಯೋವನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಲು `APP_MODE=community` ಅನ್ನು ಸ್ಪಷ್ಟವಾಗಿ ಹೊಂದಿಸಿ. ಈ ಕಾರ್ಯವಿಧಾನಗಳು ತಮ್ಮದೇ ಆದ ಖಾತೆಗಳು ಮತ್ತು ಅನುಮತಿಗಳನ್ನು ಬಳಸುತ್ತವೆ. ವಿಧಾನಗಳನ್ನು ಬದಲಾಯಿಸುವುದರಿಂದ ಸಂಗ್ರಹಿಸಿದ ದತ್ತಾಂಶವನ್ನು ಉಳಿಸಿಕೊಳ್ಳಲಾಗುತ್ತದೆ. ಕ್ಯಾಟಲಾಗ್ ವಿಧಾನವು ಅದರ API ಮೂಲಕ ಅಥವಾ ಕಾಯ್ದಿರಿಸಿದ CAD ಕೆಲಸವನ್ನು ಪುನರಾರಂಭಿಸುವ ಮೂಲಕ ಖಾಸಗಿ ಸಮುದಾಯದ ಇತಿಹಾಸವನ್ನು ಬಹಿರಂಗಪಡಿಸುವುದಿಲ್ಲ.

[Neofab ಸ್ಟುಡಿಯೊ](../../docs/NEOFAB_SETUP.md) ಆವೃತ್ತಿ-ಆಧಾರಿತ ಉತ್ಪಾದನಾ ವಿವರಣೆಗಳು, ವಸ್ತುಗಳ ಪಟ್ಟಿಗಳು ಮತ್ತು STEP/STL ರಫ್ತುಗಳೊಂದಿಗೆ ಸೀಮಿತ ಘೋಷಣಾತ್ಮಕ CAD ಅನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ. CAD ಮತ್ತು AI ಐಚ್ಛಿಕವಾಗಿರುತ್ತವೆ. AI ಪ್ರಸ್ತಾವನೆಗಳಿಗೆ ಪರಿಶೀಲನೆ ಮತ್ತು ಪ್ರತ್ಯೇಕ ಅರ್ಜಿ ಪ್ರಕ್ರಿಯೆ ಅಗತ್ಯ; ಅವು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಆದೇಶಗಳನ್ನು ಪ್ರಕಟಿಸುವುದಿಲ್ಲ ಅಥವಾ ಜ್ಯಾಮಿತಿಯನ್ನು ನಿರ್ಮಿಸುವುದಿಲ್ಲ. CAM, ಜಿ-ಕೋಡ್ ಮತ್ತು ಭೌತಿಕ ಉತ್ಪಾದನಾ ಮೌಲ್ಯೀಕರಣವನ್ನು ಇಲ್ಲಿ ಅಳವಡಿಸಲಾಗಿಲ್ಲ.

## ಮಾಹಿತಿ ಹಕ್ಕು ಮತ್ತು ಗೌಪ್ಯತೆ

MIT ಸಾಫ್ಟ್‌ವೇರ್ ಪರವಾನಗಿ, ಆಮದು ಮಾಡಲಾದ ವ್ಯಾಪಾರ ದಾಖಲೆಗಳಿಗೆ ಯಾವುದೇ ಹಕ್ಕುಗಳನ್ನು ನೀಡುವುದಿಲ್ಲ. Google ಮ್ಯಾಪ್ಸ್, 2ಜಿಐಎಸ್, ಯಾಂಡೆಕ್ಸ್ ಮ್ಯಾಪ್ಸ್ ಅಥವಾ ಇತರ ಮೂಲಗಳಿಂದ ಡೇಟಾವನ್ನು ನಕಲು ಮಾಡಲು, ಕೇವಲ ಮೂಲವನ್ನು ಉಲ್ಲೇಖಿಸುವುದು ಮಾತ್ರ ಸಾಲದು. ಡೇಟಾಸೆಟ್ ಅನ್ನು ಬಳಸುವ ಮೊದಲು, ಸಂಗ್ರಹಣೆ, ಪ್ರಕಟಣೆ ಮತ್ತು ಮರುಹಂಚಿಕೆಗಾಗಿ ಅನುಮತಿಗಳನ್ನು ಪರಿಶೀಲಿಸಿ. [ಡೇಟಾ ಮೂಲ ಮತ್ತು ಪರಿಶೀಲನಾ ವ್ಯಾಪ್ತಿ](../../docs/DATA_PROVENANCE.md) ಅನ್ನು ನೋಡಿ.

ತಾವೇ ಪ್ರಕಟಿಸಿದ ಸಂಪರ್ಕ ವಿವರಗಳು ಸಾರ್ವಜನಿಕವಾಗಿರುತ್ತವೆ; ನಿರ್ವಹಣಾ ಕೀಗಳು ಖಾಸಗಿಯಾಗಿರುತ್ತವೆ. ಸಾರ್ವಜನಿಕವಾಗಿ ಲಭ್ಯವಿರುವ ಡೈರೆಕ್ಟರಿಗಳಿಂದ ಡೇಟಾಬೇಸ್‌ಗಳು ಮತ್ತು ಬ್ಯಾಕಪ್‌ಗಳನ್ನು ಹೊರಗಿಡಿ ಮತ್ತು ತಿದ್ದುಪಡಿಗಳು ಮತ್ತು ತೆಗೆದುಹಾಕುವ ವಿನಂತಿಗಳಿಗಾಗಿ ಒಂದು ಸಂಪರ್ಕವನ್ನು ಒದಗಿಸಿ. ಅನುಷ್ಠಾಪಿಸುವ ಮೊದಲು [ಗೋಪ್ಯತೆ](../../PRIVACY.md) ಮತ್ತು [ಭದ್ರತೆ](../../SECURITY.md) ಬಗ್ಗೆ ಓದಿ.

GitHub ಕ್ರಿಯೆಗಳು ಪ್ರಕಾರಗಳನ್ನು, API ಮತ್ತು ಬ್ರೌಸರ್ ಕಾರ್ಯಪ್ರವಾಹಗಳನ್ನು ಮತ್ತು ಡೀಫಾಲ್ಟ್ ಮತ್ತು ಸ್ಥಳೀಯ CAD ಕಂಟೈನರ್‌ಗಳನ್ನು ಪರಿಶೀಲಿಸುತ್ತವೆ. ಪರೀಕ್ಷೆಗಳು ಕಲ್ಪಿತ ದಾಖಲೆಗಳನ್ನು ಬಳಸುತ್ತವೆ. ನಿಖರವಾದ ಪುರಾವೆ, ವ್ಯಾಪ್ತಿ ಮತ್ತು ಉಳಿದ ಮಿತಿಗಳನ್ನು [ಮಾನ್ಯತೆ](../../docs/VALIDATION.md) ಮತ್ತು [ಉತ್ಪಾದನಾ ವ್ಯಾಪ್ತಿ](../../docs/PRODUCT.md)ಯಲ್ಲಿ ದಾಖಲಿಸಲಾಗುತ್ತದೆ.

ಇಂಗ್ಲಿಷ್‌ನಲ್ಲಿರುವ README ಸಂಪೂರ್ಣ ಅನುವಾದಿತ ಆವೃತ್ತಿಗಳಿಗೆ ಉಲ್ಲೇಖವಾಗಿದೆ. [ಭಾಷಾ ಸೂಚಿಕೆ](../../docs/i18n/README.md) ಅನುವಾದ ನಿರ್ವಹಣೆ ಮತ್ತು ಪರಿಶೀಲನೆಗೆ ಸಂಬಂಧಿಸಿದ ಮಾಹಿತಿಯನ್ನು ಒಳಗೊಂಡಿದೆ. ಇಂಟರ್‌ಫೇಸ್‌ನ ಸ್ಥಳೀಕರಣವು ಬಳಕೆದಾರರು ಬರೆದ ಪಟ್ಟಿಗಳು, ಯೋಜನೆಯ ವಿಷಯ ಅಥವಾ ಎಲ್ಲಾ ಬಾಹ್ಯ ತಾಂತ್ರಿಕ ಮಾಹಿತಿಯನ್ನು ಅನುವಾದಿಸುವುದಿಲ್ಲ.
