मानचित्र पर किसी निर्माता को खोजें, उनकी क्षमताओं की जांच करें और सीधे उनसे संपर्क करें। यदि आपका कार्यशाला सूचीबद्ध नहीं है, तो उसके संपर्क और सेवाओं को जोड़ें: यह तुरंत सूचीबद्ध हो जाएगा। बाद में अपनी सूची को संपादित या हटाने के लिए निजी प्रबंधन लिंक को सहेजें। डिफ़ॉल्ट कैटलॉग में कोई खाता, ईमेल पुष्टिकरण या अनुमोदन कतार नहीं है।

OpenPrint को Node.js 24 और स्थानीय SQLite के साथ चलाएं। Vercel, Supabase, एक ईमेल प्रदाता, भुगतान किए गए एआई और तृतीय-पक्ष लॉगिन की आवश्यकता नहीं है। GitHub स्रोत और रिलीज़ को होस्ट करता है; एक साझा वेबसाइट, जिसमें सबमिशन स्वीकार किए जाते हैं, के लिए एक चालू API सर्वर की आवश्यकता होती है। केवल [GitHub पृष्ठ](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) Node.js API को नहीं चला सकते हैं या आगंतुकों के परिवर्तनों को बनाए नहीं रख सकते।

## सूची की विशेषताएं

- [कार्यशाला नेटवर्क](../../docs/WORKSHOP_NETWORK.md). आपका ऑर्डर और फ़ाइल चुनी गई कार्यशाला के नोड पर सहेजे जाएँगे।
- नाम, शहर और तकनीक के आधार पर खोजें। मानचित्र में सूची के पृष्ठों से स्वतंत्र रूप से मिलान करने वाले स्थान शामिल हैं।
- बिना खाते के प्रकाशित करें। किसी मानचित्र बिंदु का चयन करें या निर्देशांक दर्ज करें; निर्देशांक के बिना की सूचियाँ खोज योग्य रहेंगी।
- किसी एक लिस्टिंग को संपादित करें या हटाएं, साथ ही उसके निजी लिंक को भी। संस्करण जाँच, विभिन्न टैब में होने वाले परस्पर विरोधी संपादन से सुरक्षा प्रदान करती है।
- प्रकाशित करने से पहले मौजूदा स्टूडियो खोजें। समान नाम, शहर और पते वाली प्रविष्टियाँ स्वचालित रूप से अस्वीकार कर दी जाएंगी।
- स्रोत का उल्लेख करते हुए एक कैटलॉग आयात करें। ऑपरेटर द्वारा किए गए आयात, स्वयं प्रकाशित सूचियों को अधिलेखित नहीं कर सकते।
- बिना API कुंजी के OpenStreetMap टाइलों को देखें। जब कोई मानचित्र प्रदर्शित किया जाता है, तो टाइलें लोड होती हैं, जिसमें डिफ़ॉल्ट लैंडिंग पृष्ठ भी शामिल है।
- भाषा मेनू से इंटरफ़ेस भाषा चुनें। ऊपर दिए गए भाषा अनुक्रमणिका के माध्यम से अपनी भाषा में पूरी README पढ़ें।

यह प्रकाशन किसी व्यवसाय के स्वामित्व या सेवा की गुणवत्ता की पुष्टि नहीं करता है। उपकरण, क्षमताओं और शर्तों की स्टूडियो से पुष्टि करें। जिस भी व्यक्ति के पास निजी प्रबंधन लिंक है, वह उस सूची को नियंत्रित कर सकता है। इसे निजी रखें; ईमेल पुनर्प्राप्ति का कोई विकल्प नहीं है। [स्व-प्रकाशन मार्गदर्शिका](../../docs/OPEN_CATALOG.md) पढ़ें।

## अपना इंस्टेंस चलाएं

Node.js 24 स्थापित करें, इस रिपॉजिटरी को क्लोन करें और चलाएँ:

```sh
npm ci
npm run build
cp .env.example .env
npm start
```

ओपन `http://localhost:3000`। डिफ़ॉल्ट `APP_MODE=catalog` के लिए किसी व्यवस्थापक या उपयोगकर्ता सेटअप की आवश्यकता नहीं है। `APP_URL`, HTTPS और बैकअप को [स्व-होस्टिंग गाइड](../../docs/SELF_HOSTING.md) का उपयोग करके कॉन्फ़िगर करें। Docker कंपोज़ भी उपलब्ध है: `docker compose up --build -d`।

समर्थित परिनियोजन में एक स्थानीय डिस्क पर SQLite के साथ एक एप्लिकेशन प्रक्रिया शामिल है। स्वचालित प्रकाशन और अनुरोध कोटा, मॉडरेशन कतार के बिना दुरुपयोग को सीमित करते हैं। एक साझा कार्यालय आईपी एक प्रकाशन कोटा साझा कर सकता है। सार्वजनिक इंस्टेंस खोलने से पहले [सीमाओं और प्रबंधन-लिंक व्यवहार](../../docs/OPEN_CATALOG.md) देखें।

किसी मौजूदा डेटासेट के अधिकारों की जांच करने के बाद, [कैटलॉग आयात CLI](../../docs/CATALOG_IMPORT.md) का उपयोग करें। इंस्टेंस डेटासेट, अपलोड और बैकअप रिपॉजिटरी या कंटेनर छवियों में शामिल नहीं होते हैं।

## वैकल्पिक सामुदायिक और Neofab मोड

निजी परियोजनाओं, प्रदाता उद्धरणों, मॉडल लाइब्रेरी और Neofab स्टूडियो को सक्षम करने के लिए `APP_MODE=community` को स्पष्ट रूप से सेट करें। ये वर्कफ़्लो अपने स्वयं के खातों और अनुमतियों का उपयोग करते हैं। मोड बदलने से संग्रहीत डेटा सुरक्षित रहता है। कैटलॉग मोड अपने API के माध्यम से निजी समुदाय के इतिहास को प्रदर्शित नहीं करता है और न ही रुके हुए CAD कार्यों को फिर से शुरू करता है।

[Neofab स्टूडियो](../../docs/NEOFAB_SETUP.md) संस्करण-आधारित निर्माण विवरण, सामग्री की सूची और सीमांकित घोषणात्मक CAD का समर्थन करता है, साथ ही STEP/STL प्रारूप में निर्यात की सुविधा भी देता है। CAD और एआई वैकल्पिक हैं। एआई प्रस्तावों की समीक्षा की जानी चाहिए और इसके लिए एक अलग आवेदन प्रक्रिया है; ये स्वचालित रूप से ऑर्डर प्रकाशित नहीं करते हैं या ज्यामिति नहीं बनाते हैं। CAM, जी-कोड और भौतिक निर्माण सत्यापन को अभी तक लागू नहीं किया गया है।

## डेटा अधिकार और गोपनीयता

MIT सॉफ़्टवेयर लाइसेंस आयातित व्यावसायिक रिकॉर्ड के लिए कोई अधिकार प्रदान नहीं करता है। केवल स्रोत का उल्लेख करने से Google मैप्स, 2जीआईएस, यांडेक्स मैप्स या अन्य स्रोतों से डेटा की प्रतिलिपि बनाने की अनुमति नहीं मिलती है। किसी डेटासेट का उपयोग करने से पहले, भंडारण, प्रकाशन और पुनर्वितरण के लिए अनुमतियों की जाँच करें। [डेटा की उत्पत्ति और समीक्षा की सीमाएँ](../../docs/DATA_PROVENANCE.md) देखें।

स्वयं प्रकाशित संपर्क विवरण सार्वजनिक हैं; प्रबंधन कुंजियाँ निजी हैं। डेटाबेस और बैकअप को सार्वजनिक रूप से उपलब्ध निर्देशिकाओं से बाहर रखें, और सुधार और हटाने के अनुरोधों के लिए एक संपर्क प्रदान करें। तैनाती से पहले [गोपनीयता](../../PRIVACY.md) और [सुरक्षा](../../SECURITY.md) संबंधी जानकारी पढ़ें।

## विकास और अनुवाद

```sh
npm run dev
npm run check
npx playwright install chromium
npm run test:e2e
npm run format:check
```

GitHub क्रियाएँ प्रकारों, API और ब्राउज़र वर्कफ़्लो की जाँच करती हैं, और डिफ़ॉल्ट और मूल CAD कंटेनरों की भी जाँच करती हैं। परीक्षणों में काल्पनिक रिकॉर्ड का उपयोग किया जाता है। सटीक प्रमाण, कवरेज और शेष सीमाएँ [सत्यापन](../../docs/VALIDATION.md) और [उत्पाद क्षेत्र](../../docs/PRODUCT.md) में दर्ज की जाती हैं।

अंग्रेजी में दी गई README फ़ाइल, पूर्ण अनुवादित संस्करणों के लिए संदर्भ है। [भाषा अनुक्रमणिका](../../docs/i18n/README.md) में अनुवाद के रखरखाव और समीक्षा की सीमाओं के बारे में जानकारी दी गई है। इंटरफ़ेस का स्थानीयकरण, उपयोगकर्ताओं द्वारा बनाई गई सूचियों, परियोजना सामग्री या हर बाहरी तकनीकी निदान का अनुवाद नहीं करता है।

## लाइसेंसिंग और योगदान

मूल स्रोत कोड, यूआई, SVG चित्र, दस्तावेज़ और पैरामीट्रिक जेनरेटर [MIT लाइसेंस](../../LICENSE) के तहत उपलब्ध हैं। निर्भरताएँ अपने स्वयं के लाइसेंस और सूचनाओं को बरकरार रखती हैं। उपयोगकर्ता मॉडल के लिए उनके लेखकों द्वारा चुना गया अलग लाइसेंस होता है। काल्पनिक डेमो प्रोफ़ाइल और डेमो तकनीकी आवश्यकताओं के पाठ, तथा तीन उत्पन्न डेमो डिज़ाइन CC0 के तहत समर्पित हैं; जेनरेटर MIT के तहत रहता है। [तृतीय-पक्ष सूचनाएँ](../../THIRD_PARTY_NOTICES.md) देखें।

यह स्वतंत्र कार्यान्वयन [3d-online.app](https://3d-online.app) के विचार को आगे बढ़ाता है। मूल उत्पादन खाते, गुप्त जानकारी, निजी गिट इतिहास और उपयोगकर्ता फ़ाइलें इसमें शामिल नहीं हैं। अनुकूलित MIT Neofab CAD कंपाइलर अपने [मूल लाइसेंस और उत्पत्ति संबंधी सूचना](../../cad-worker/NOTICE.md) को बरकरार रखता है।

योगदान में कोड, अनुवाद में सुधार, उपयोगिता में वृद्धि, खुले पैरामीट्रिक भागों, स्थापना जाँच और वास्तविक कार्यशालाओं से प्राप्त प्रतिक्रिया शामिल हो सकते हैं। [CONTRIBUTING.md](../../CONTRIBUTING.md) से शुरुआत करें।
