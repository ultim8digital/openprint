# OpenPrint

**Открытый каталог студий печати и мастерских. Без регистрации и модераторов.**

[Languages / Языки](../../docs/i18n/README.md) · [English](../../README.md) · [Русский](../../docs/readme/README.ru.md)

Найдите мастерскую на карте, уточните её возможности и свяжитесь напрямую. Если вашей мастерской нет, добавьте контакты и услуги: карточка появится сразу. Сохраните личную ссылку управления, чтобы позднее исправить или удалить запись. В основном режиме каталога нет аккаунтов, подтверждения почты и очереди одобрения.

OpenPrint работает с Node.js 24 и локальной SQLite. Vercel, Supabase, почтовый сервис, платный ИИ и сторонний вход не требуются. GitHub хранит исходники и релизы; общему сайту с добавлением записей нужен работающий API-сервер. Одного [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) недостаточно: он не выполняет Node.js API и не сохраняет изменения посетителей.

## Возможности каталога

- Поиск по названию, городу и технологии. Карта показывает подходящие точки независимо от страницы списка.
- Публикация без аккаунта. Выберите точку на карте или введите координаты; записи без координат остаются доступны в поиске.
- Изменение и удаление своей карточки по личной ссылке. Проверка версии защищает от конфликтующих правок в разных вкладках.
- Поиск существующих студий перед публикацией. Точные дубли названия, города и адреса отклоняются автоматически.
- Импорт каталога с указанием источника. Импорт оператора не перезаписывает самостоятельные публикации.
- Карта OpenStreetMap без API-ключа. Тайлы загружаются при показе карты, в том числе на начальной странице.
- Выбор языка интерфейса в меню языков. Полные переводы README доступны в указателе языков выше.

Публикация не подтверждает принадлежность бизнеса или качество услуг. Оборудование, возможности и условия уточняйте у студии. Любой обладатель личной ссылки может управлять этой записью. Храните ссылку приватно; восстановления через почту нет. Подробнее — в [инструкции самостоятельной публикации](../../docs/OPEN_CATALOG.md).

## Запуск своего экземпляра

Установите Node.js 24, клонируйте репозиторий и выполните:

```sh
npm ci
npm run build
cp .env.example .env
npm start
```

Откройте `http://localhost:3000`. Режим по умолчанию `APP_MODE=catalog` не требует создания администратора или пользователей. Настройте `APP_URL`, HTTPS и резервные копии по [инструкции установки](../../docs/SELF_HOSTING.md). Также доступен Docker Compose: `docker compose up --build -d`.

Поддерживается один процесс приложения с SQLite на локальном диске. Автоматические квоты публикаций и запросов ограничивают злоупотребления без очереди модерации. Общий IP офиса может разделять одну квоту публикаций. Перед публичным запуском изучите [ограничения и работу личных ссылок](../../docs/OPEN_CATALOG.md).

Существующую базу подключайте через [CLI импорта каталога](../../docs/CATALOG_IMPORT.md) после проверки прав на данные. Базы отдельных установок, загруженные файлы и резервные копии не поставляются в репозитории и контейнерах.

## Необязательный режим сообщества и Neofab

Явно задайте `APP_MODE=community`, чтобы включить приватные проекты, предложения исполнителей, библиотеку моделей и Neofab Studio. В этих сценариях действуют отдельные аккаунты и права доступа. Переключение режимов сохраняет данные. Режим каталога не раскрывает приватную историю сообщества через API и не запускает накопленные CAD-задания.

[Neofab Studio](../../docs/NEOFAB_SETUP.md) поддерживает версии производственного ТЗ, спецификации состава и ограниченную декларативную CAD-геометрию с экспортом STEP/STL. CAD и ИИ необязательны. Предложения ИИ требуют проверки и отдельного применения; они не публикуют заказы и не строят геометрию автоматически. CAM, G-code и проверка физической пригодности изделий не реализованы.

## Права на данные и приватность

Лицензия MIT на программу не предоставляет прав на импортированные сведения об организациях. Одно указание источника не разрешает копирование данных Google Maps, 2ГИС, Яндекс Карт и других сервисов. До использования базы проверьте разрешения на хранение, публикацию и распространение. Подробнее — в [документе о происхождении данных и границах проверки](../../docs/DATA_PROVENANCE.md).

Контакты самостоятельных публикаций общедоступны, ключи управления приватны. Не размещайте базы и резервные копии в публично доступных папках; укажите контакт для исправлений и запросов на удаление. Перед запуском изучите [правила приватности](../../PRIVACY.md) и [безопасность](../../SECURITY.md).


Английский README служит исходником полных переводов. В [указателе языков](../../docs/i18n/README.md) описаны сопровождение переводов и границы их проверки. Локализация интерфейса не переводит пользовательские карточки, содержимое проектов и все внешние технические сообщения.
