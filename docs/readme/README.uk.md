Знайдіть майстерню на карті, перегляньте її можливості та зв’яжіться з нею безпосередньо. Якщо вашої майстерні немає в списку, додайте її контактні дані та інформацію про послуги: інформація про майстерню з’явиться одразу. Збережіть посилання для особистого доступу, щоб пізніше редагувати або видалити інформацію про вашу майстерню. У стандартному каталозі немає облікових записів, підтвердження електронною поштою або черги на затвердження.

Запустіть OpenPrint з Node.js 24 і локальним SQLite. Vercel, Supabase, провайдер електронної пошти, платний ШІ та вхід через сторонні сервіси не потрібні. GitHub розміщує вихідний код і публікує оновлення; для спільного вебсайту, який приймає матеріали, потрібен працюючий API сервер. Лише [GitHub сторінки](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) не можуть запустити Node.js API або зберігати зміни, внесені відвідувачами.

## Функції каталогу

- [Мережа майстерень](../../docs/WORKSHOP_NETWORK.md). Ваше замовлення та файл зберігатимуться на вузлі обраної майстерні.
- Пошук за назвою, містом і технологією. На карті відображаються відповідні об’єкти незалежно від нумерації сторінок у списку.
- Опублікуйте без створення облікового запису. Оберіть точку на карті або введіть координати; оголошення без координат залишаються доступними для пошуку.
- Відредагуйте або видаліть один запис разом із його приватним посиланням. Перевірка версій захищає від конфліктних змін, внесених у різних вкладках.
- Знайдіть наявні студії, перш ніж додавати нову. Точні збіги назви, міста та адреси автоматично відхиляються.
- Імпортуйте каталог із зазначенням джерела. Оператори не можуть перезаписувати власні оголошення.
- Переглядайте OpenStreetMap фрагменти карти без API ключа. Фрагменти карти завантажуються під час відображення карти, зокрема й основної сторінки.
- Оберіть мову інтерфейсу в мовному меню. Ознайомтеся з повним файлом README вашою мовою, перейшовши за посиланням у мовному індексі, що розташований вище.

Розміщення інформації не підтверджує право власності на бізнес або якість послуг. Уточнюйте наявність обладнання, можливості та умови безпосередньо в студії. Будь-хто, хто має посилання для приватного керування, може редагувати цю інформацію. Зберігайте її в приватному режимі, оскільки відновлення доступу за допомогою електронної пошти неможливе. Ознайомтеся з [інструкцією щодо самостійного розміщення інформації](../../docs/OPEN_CATALOG.md).

## Запустіть власну копію

Встановіть Node.js 24, скопіюйте цей репозиторій і запустіть:

```sh
npm ci
npm run build
cp .env.example .env
npm start
```

Open `http://localhost:3000`. Для стандартної `APP_MODE=catalog` не потрібне налаштування адміністратором або користувачем. Налаштуйте `APP_URL`, HTTPS та резервне копіювання, використовуючи [інструкцію з самостійного розміщення](../../docs/SELF_HOSTING.md). Docker Також доступний Compose: `docker compose up --build -d`.

Підтримується розгортання у вигляді одного процесу програми з SQLite на локальному диску. Автоматична публікація та обмеження кількості запитів запобігають зловживанням без необхідності черги модерації. Спільна IP-адреса офісу може використовувати спільну квоту на публікації. Перегляньте [інформацію про обмеження та поведінку системи управління](../../docs/OPEN_CATALOG.md), перш ніж відкривати публічний екземпляр.

Використовуйте [інструмент командного рядка для імпорту каталогу](../../docs/CATALOG_IMPORT.md) для наявного набору даних після перевірки прав на нього. Набори даних, завантаження та резервні копії не включаються до репозиторію або образів контейнерів.

## Необов’язковий режим спільноти та Neofab

Встановіть значення `APP_MODE=community`, щоб увімкнути приватні проєкти, пропозиції від постачальників, бібліотеку моделей і Neofab Studio. Ці робочі процеси використовують власні облікові записи та дозволи. Перемикання режимів зберігає збережені дані. У режимі каталогу не відображається історія приватної спільноти через його API і не відновлюється призупинена CAD робота.

[Neofab Studio](../../docs/NEOFAB_SETUP.md) підтримує версіоновані технічні завдання для виробництва, специфікації матеріалів та обмежену декларативну CAD з експортом у формати STEP/STL. CAD та штучний інтелект є необов’язковими. Пропозиції, що використовують штучний інтелект, потребують перевірки та окремого етапу застосування; вони не автоматично публікують замовлення або створюють геометрію. CAM, G-код та перевірка фізичної придатності виробів не реалізовані.

Ліцензія на програмне забезпечення MIT не надає прав на використання імпортованих бізнес-даних. Просте зазначення авторства не дозволяє копіювати дані з Google Maps, 2GIS, Яндекс.Карти або інших джерел. Перед використанням набору даних перевірте наявність дозволів на зберігання, публікацію та розповсюдження. Див. розділ [походження даних та межі їх використання](../../docs/DATA_PROVENANCE.md).

Контактні дані, додані користувачем самостійно, є загальнодоступними; ключі керування є конфіденційними. Зберігайте бази даних і резервні копії поза загальнодоступними каталогами та надайте контактну особу для отримання запитів на внесення виправлень і видалення даних. Перед розгортанням ознайомтеся з інформацією про [конфіденційність](../../PRIVACY.md) і [безпеку](../../SECURITY.md).
