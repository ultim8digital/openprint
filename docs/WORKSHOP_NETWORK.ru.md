# Сеть мастерских OpenPrint

Заказчику достаточно браузера. Владелец домашнего принтера может присоединиться к узлу местного сообщества или запустить собственный узел. На одном узле могут работать несколько независимых мастерских. Каждая сама выбирает, публиковать ли свои координаты и принимать ли изготовление заказа.

## Запустить мастерскую

Установите Node.js 24, откройте каталог проекта и выполните команды.

```sh
npm ci
npm run build
cp .env.example .env
```

Укажите в `.env` значение `APP_MODE=community` и запустите `npm start`. Откройте `http://localhost:3000`, зарегистрируйтесь и перейдите в профиль участника. Заполните название, город и технологии. Для показа на карте добавьте координаты. Включите «Показывать мою мастерскую на других узлах OpenPrint» и сохраните профиль.

Для заказов через интернет понадобится доступный HTTPS-адрес самого узла. Укажите его в `APP_URL`. База SQLite и файлы находятся у владельца узла. Порядок настройки HTTPS и резервного копирования описан в [руководстве по размещению](SELF_HOSTING.md).

## Соединить узлы

Передайте адрес своей мастерской владельцу другого узла. Он добавляет этот адрес в `OPENPRINT_PEERS` в своём `.env` и перезапускает OpenPrint. Несколько адресов разделяются запятыми. После этого в разделе «Каталог и карта → Сеть мастерских» появляются мастерские подключённого узла. Для обмена в обе стороны оба оператора добавляют адрес соседа.

Опробовать весь путь можно на одном компьютере. После сборки запустите команды в двух терминалах с новыми папками данных.

```sh
APP_MODE=community HOST=127.0.0.1 PORT=3102 APP_URL=http://127.0.0.1:3102 DATA_DIR=.local/workshop-b MAP_TILES=off npm start
```

```sh
APP_MODE=catalog HOST=127.0.0.1 PORT=3101 APP_URL=http://localhost:3101 DATA_DIR=.local/directory-a OPENPRINT_PEERS=http://127.0.0.1:3102 MAP_TILES=off npm start
```

На первом узле создайте профиль мастерской. Во втором профиле браузера откройте `http://localhost:3101/network` как заказчик. Если профиль мастерской создан после открытия карты, обновите страницу через 30 секунд. Режим `MAP_TILES=off` использует береговые линии из комплекта приложения. Для показа улиц включите `MAP_TILES=osm`.

На снимках видна мастерская из тестового сценария на карте с отключёнными внешними тайлами. [Экран компьютера](images/workshop-network-desktop.png) · [Экран телефона](images/workshop-network-mobile.png)

## Оформить и выполнить заказ

1. Откройте «3D-инструменты». Выберите пластину, втулку, блок или откройте свой STL/OBJ. На узле сообщества доступна также библиотека опубликованных моделей. Поверните модель, измените размеры шаблона или масштаб сетки. Размеры указаны в миллиметрах.
2. Нажмите «Выберите исполнителя» и откройте мастерскую на карте или в списке. Можно начать и с карты, сначала выбрать мастерскую, а затем подготовить модель.
3. Параметры шаблона перейдут в редактор мастерской. Для сетки откроется вторая вкладка. Оставьте первую открытой и во второй нажмите «Открыть STL или OBJ» рядом с адресом исходного узла. При блокировке всплывающих окон модель можно передать скачанным файлом.
4. Нажмите «Личный запрос», войдите или создайте аккаунт на узле мастерской. Укажите материал, количество и требования. На последнем шаге проверьте получателя и вложение. При публикации файл загружается на этот узел. Сохранённый черновик описания можно открыть после перезагрузки вкладки, файл потребуется выбрать заново.
5. Исполнитель получает личный запрос и предлагает цену и срок. Заказчик принимает конкретное предложение. После этого мастер скачивает файл, изготавливает изделие и отмечает передачу. Заказчик подтверждает получение. Об оплате и доставке стороны договариваются напрямую.

Карта показывает согласившихся участников подключённых узлов. Узел каталога хранит список соседей и кратковременно кэширует их публичные профили. Заказ, переписка и вложение хранятся на узле выбранной мастерской. Заказ остаётся доступен по своему адресу, даже если узел, через который нашли мастера, выключен.
