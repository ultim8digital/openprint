# Каталог студий и карта

OpenPrint показывает два вида записей: профили участников сообщества и справочный каталог, который подключает оператор. Каталог хранится в локальной SQLite отдельно от аккаунтов. Импорт не создаёт пользователей, пароли, отметки проверки или готовность принимать заказы.

На `/studios` доступны общий поиск и фильтр источника. Ссылка `/studios?view=map` сразу открывает карту. Карта получает все подходящие точки независимо от страницы списка; записи без координат остаются в списке. Тайлы OpenStreetMap загружаются только при открытии карты. Данные каталога продолжают работать без Supabase и Vercel.

## Подготовить файл

Принимается JSON-массив со стабильным `id` каждой записи:

```json
[
  {
    "id": "example-workshop-1",
    "name": "Example workshop",
    "city": "Example city",
    "region": "Example region",
    "country": "",
    "description": "Public workshop description",
    "technologies": ["FDM"],
    "materials": ["PLA", "PETG"],
    "website": "https://workshop.example.org",
    "phone": "",
    "address": "",
    "lat": 51.5,
    "lng": -0.1
  }
]
```

Неизвестные координаты задаются парой `null`; координата `0` допустима. Название и город сохраняются как текст. Для неизвестной страны используйте пустую строку; импорт не определяет страну по городу. Поддерживаются известные обозначения исходного каталога: `FDM/FFF` → `FDM`, `SLA/DLP/LCD` → `SLA`, `SLM/DMLS (металл)` → `DMLS`. Остальные названия технологий сохраняются.

Разрешённые поля ограничены карточкой организации: название, расположение, описание, технологии, материалы, публичный сайт, телефон и адрес. Поля `email`, `hours`, `rating`, `reviews` и прочие дополнительные поля не импортируются. Ссылки должны использовать HTTP(S) без встроенных логина и пароля. Скрипт проверяет весь файл до изменения базы; ошибки не превращаются в тихий частичный импорт.

## Сначала проверить

```sh
npm run catalog:import -- \
  --file /absolute/path/studios.json \
  --source my-directory \
  --source-name "My directory" \
  --source-url https://directory.example.org
```

Без `--apply` это только проверка и подсчёт: база и папка данных не создаются. Файл ограничен 50 MiB, один импорт — от 1 до 50 000 записей. Пустой снимок отклоняется. Ключ `--source` определяет самостоятельный источник и должен сохраняться при его обновлении.

## Подключить к экземпляру

Сделайте резервную копию действующего экземпляра по [инструкции](SELF_HOSTING.md). Укажите его `DATA_DIR` и добавьте `--apply`:

```sh
DATA_DIR=/absolute/path/community-data npm run catalog:import -- \
  --file /absolute/path/studios.json \
  --source my-directory \
  --source-name "My directory" \
  --source-url https://directory.example.org \
  --apply
```

Для локального демо используется `DATA_DIR=.local/demo`. Учётные записи и проекты демо остаются вымышленными; подключённый оператором каталог может содержать реальные организации. Не открывайте демо-режим в интернете.

Студии также могут [публиковать себя без аккаунта](OPEN_CATALOG.md). Самостоятельные записи хранятся отдельно и не заменяются импортом. Точный дубль названия, города и адреса между импортом и самостоятельной записью отклоняет весь импорт.

Применение атомарно заменяет снимок **только указанного источника**. Записи с тем же исходным `id` сохраняют адреса карточек; отсутствующие в новом снимке удаляются из этого источника. Профили участников, проекты и другие источники не изменяются. Данные доступны после обновления страницы. При обновлении кода с версии 0.3/0.4 сначала перезапустите приложение для миграции схемы 4/5 → 6.

## Что видит посетитель

- Справочная запись имеет подпись источника и дату импорта. Дата импорта не означает, что организация недавно подтвердила сведения.
- Связь со справочной студией идёт через указанный сайт или телефон. Создание заявки внутри OpenPrint доступно профилям зарегистрированных участников только в дополнительном режиме `APP_MODE=community`.
- Импортированные и самостоятельные записи имеют разные подписи происхождения. Публикация не подтверждает принадлежность бизнеса или качество услуг; отметки проверки модератором у каталога нет.
- Карта показывает до 50 000 подходящих точек; при превышении явно предлагает сузить поиск. Пагинация карточек не ограничивает точки карты.
- Отсутствующие координаты не заменяются выдуманными координатами центра города.

Источник JSON и SQLite остаются в приватной папке данных и резервных копиях. Каталоги конкретного оператора не поставляются в публичном репозитории; лицензия MIT на код не назначает лицензию сторонним данным. Оператор выбирает данные для своего экземпляра и обрабатывает запросы на исправление или удаление. Для удаления отдельной записи обновите непустой исходный снимок и повторите импорт того же источника. Полное удаление источника через этот CLI пока не предусмотрено.
